# 平急双模态：任务需求的统一表征 与 耦合分析建模（表达式构造手册）

> 目的：把「平急双模态需求统一表征 + 平急耦合分析」从一句话命题，变成能写进论文 Model 章节的目标函数、约束与指标。
> 方法：从人道物流预置 / 双使命设施 / 库存配给 / 柔性容量 四条线借现成数学语言，再迁移到无人机机巢选址。

---

## 零、先立符号（论文符号表底稿）

集合
- $I$：任务需求点（平时=配送客户点/巡检区段；应急=灾区/投送点）
- $J$：候选机巢/起降点
- $S$：应急情景集合，$S=\{1..s..n\}$，另设 $s=0$ 表示**平时态**
- $M=\{P,E\}$：任务模态（P 平时、E 应急）
- $T$：时段，$t=1..T$（转换时间以"期"为单位）
- $K$：机巢容量等级

参数
- $d^P_{i,t}$：平时任务需求量（架次/任务量）
- $d^E_{i,t,s}$：情景 $s$ 下应急任务需求量
- $p_s$：情景发生概率；$p_0$ = 平时时间占比（如 0.99），$\sum_{s\in S}p_s = 1-p_0$
- $f_j$：建巢固定成本；$\gamma_{jk}$：容量等级 $k$ 的配置成本
- $C_{jk}$：容量等级 $k$ 的机巢容量（同时停靠/起降/充换电能力）
- $\mu^P_{j,t},\ \mu^E_{j,t}$：单位任务容量占用系数（**平时/应急异构**：应急任务航程远、载荷重 → $\mu^E>\mu^P$）
- $\pi^P,\ \pi^E$：单位未满足需求惩罚（平时=违约/流失成本；应急=剥夺成本，$\pi^E \gg \pi^P$）
- $c^{conv}_j$：平转急切换成本；$\tau_j$：切换时长（期）；$\eta_j$：切换后容量折损系数
- $R^P,\ R^E$：平时/应急服务半径（平时严格，应急可放宽）

决策变量
- 一阶段（战略，平时定）：$y_j\in\{0,1\}$ 建巢；$k_j$ 容量等级；$r_j\ge 0$ **应急预留容量**；$q_j$ 配置无人机数；$z_{ij}\in\{0,1\}$ 需求点指派
- 二阶段（战术，情景相关）：$x^m_{ij,t,s}$ 任务分配量；$mo_{j,t,s}\in\{0,1\}$ 机巢是否处于应急态；$w_{j,t,s}\in\{0,1\}$ 发生平转急切换；$u^m_{i,t,s}$ 未满足量

## 一、统一表征：五种范式，选一到两种组合（**别全用**）

### R1 情景-概率统一（最推荐作主线）
把「平时」写成情景集合里的一个**高概率特殊情景**，两个模态就自动进入同一个目标函数：

$$\min \sum_j (f_j y_j + \gamma_{jk}) \;+\; \underbrace{p_0\, Q(y,k,r; s{=}0)}_{\text{平时态}} \;+\; \sum_{s\in S} p_s\, Q(y,k,r; s)$$

- $p_0$ = 平时时间占比，$\sum_s p_s$ = 灾年发生概率；$Q$ 是同一套第二阶段函数
- 好处：不需要"两个模型 + 一个人工折中系数"，平急的权重由**概率**自然给出，可辩护
- 出处：Salmerón & Apte (POM 2009) 两阶段随机预置；Bozorgi-Amiri 类混合不确定预置

### R2 模态增量统一（写法最省事）
需求 = **平时基线 + 模态激活增量**，全场景共用同一需求量纲和同一分配变量：

$$D_{i,t}(s) = d^P_{i,t} + \mathbb{1}[s>0]\cdot \Delta^E_{i,t,s}$$

- 应急不另立一套需求体系，而是基线上的**增量**；$mo_{j,t,s}$ 激活时增量才计入
- 好处：答辩时一句话解释清楚"统一表征"是什么；避免"两套需求两套模型"的结构性割裂

### R3 量纲统一（目标函数层面，必须二选一）
「平时成本」和「应急短缺」不同量纲不能直接相加，两条成熟出路：
- **时间统一**：两类任务都折算为响应时间/时效 —— min 平均响应时间（CARE 的做法，Duran et al. 2011）
- **货币统一**：引入**剥夺成本** $DC(\cdot)$，把"受灾人没拿到物资的痛苦"货币化，与运成本同量纲可加（Holguín-Veras et al., JOM 2013, c=552 —— 这篇是人道物流目标函数的标准引用）

### R4 多商品流统一
把两种模态当作**两种商品**在同一张网络上流动，共享节点/弧容量：

$$\sum_{m\in M}\mu^m_{j}\,x^m_{ij,t,s} \le C_{jk}, \qquad \sum_m f^m_{ab} \le u_{ab}$$

- 好处：共享容量约束（见 C1）天然写出来，是"耦合"最标准的载体

### R5 需求分级 + 阈值配给统一（耦合侧最强语言）
需求按优先级分级（应急=高、平时=低），共享同一容量/库存，用**临界水位**区分服务：

$$\underbrace{\sum_j x^E_{ij,t,s} \ge (1-\beta)d^E_{i,t,s}}_{\text{高优先级：硬约束}} , \qquad \underbrace{\sum_j x^P_{ij,t} + u^P_{i,t} = d^P_{i,t}}_{\text{低优先级：可延迟，罚}\ \pi^P}$$

- $u^P$（平时未满足量）就是"让路"的可量化形态；$r_j$（应急预留容量）就是临界水位 $K$
- 出处：Deshpande/Cohen/Donohue (Mgmt Sci 2003, c=268) 阈值配给政策；OR 2003 优先需求类（c=160）——它们证明了"简单阈值政策接近最优"，是你论文里"不必做复杂动态策略"的强力引用

## 二、耦合建模：四个通道（平急"耦合分析"的实体）

### C1 容量耦合（共享容量 + 异质占用）
$$\sum_{i}\mu^P_{j} x^P_{ij,t} \;+\; \sum_i \mu^E_{j}\, mo_{j,t,s}\, x^E_{ij,t,s} \;\le\; C_{j,k_j} \qquad \forall j,t,s$$

预留式等价的写法（更直观、更贴"平急两用"）：
$$x^P_{\cdot j,t} \le C_j - r_j,\qquad x^E_{\cdot j,t,s} \le C_j,\qquad \text{合计} \le C_j$$

- $r_j$：**应急预留容量**，一阶段决策变量 → 这就是"平时养应急"的代价载体
- 若考虑"平时任务可被应急抢占"：$r_j$ 变成可动态调整，写成 $r_{j,t}$ + 抢占变量

### C2 转换耦合（时间 / 成本 / 折损 / 转换能力上限）
$$w_{j,t,s} \ge mo_{j,t,s} - mo_{j,t-1,s}\quad(\text{切换触发})$$
$$mo_{j,t,s} \le mo_{j,t-1,s} + \sum_{\theta < t} w_{j,\theta,s}\,\mathbb{1}[t-\theta \ge \tau_j]\quad(\text{切换需}\ \tau_j\ \text{期})$$
$$C^{avail}_{j,t,s} = C_j\bigl(1-\eta_j\cdot \text{conv\_active}_{j,t,s}\bigr)\quad(\text{转换期容量折损})$$
$$\sum_j w_{j,t,s} \le N^{conv}\quad(\text{单期转换能力上限：人手/装备/空域审批有限})$$
- 目标里加 $\sum_j\sum_t c^{conv}_j w_{j,t,s}$
- 出处：TST 2015「Dynamic Facility Location with Generalized Modular Capacities」给出**任意容量等级之间切换成本矩阵**的建模与更强 LP 松弛 —— 平急切换成本正好套这个壳，且对 MILP 求解效率有直接帮助

### C3 优先级耦合（配给水位 / 让路变量）
$$r_j \ge \rho_{\min}\,C_j y_j\quad(\text{关键机巢必须留应急冗余})$$
$$u^P_{i,t} = \max\Bigl(0,\ d^P_{i,t} - \bigl(C_j-r_j - \text{应急占用}\bigr)\Bigr)\ \text{线性化}\quad(\text{平时让路的显式表达})$$
- $r_j$ 的最优性条件：**平时边际收益 = 应急短缺边际成本** 时的临界水位 —— 直接引用 Deshpande (2003) 的结构性结论
- $\rho_{\min}$ 可作敏感性参数：扫描 $\rho_{\min}$ 看平时成本如何上升 → 直接画出"平急冲突曲线"

### C4 目标耦合（把"平急矛盾"量化成指标 —— 你的创新点落点）
三种处理方式，任选：
- 加权和：$\min\ (1-\lambda)F^P + \lambda F^E$，扫 $\lambda\in[0,1]$ 得**帕累托前沿**
- ε-约束：$\min F^P \ \text{s.t.}\ F^E \le \varepsilon$（推荐：避免 $\lambda$ 主观性被审稿人攻击）
- 双目标直接求解（NSGA-II 等）

> ⚠ 只加权和、不扫 $\lambda$、不给 $\lambda$ 经济含义 = 典型审稿雷区（"创新=调参"）。

**建议自创的三个可计算指标（"耦合分析"的输出物）**
1. **平急耦合系数** $\kappa = \dfrac{F^E(y^{P*}) - F^{E*}}{F^{E*}}$：取平时最优布局，算它在应急目标上的性能退化率。$\kappa$ 越小 → 两模态越兼容
2. **转换柔性指数** $\varphi = \dfrac{\sum_j r_j}{\sum_j C_j}$：系统为应急预留的容量比例，衡量"预留了多少可切换能力"
3. **帕累托距离** $\delta = \bigl\|(\tilde F^P,\tilde F^E) - (\tilde F^{P*},\tilde F^{E*})\bigr\|_2$：归一化目标空间里"平时最优解"与"应急最优解"的距离 = 平急冲突度

这三个量目前在人道预置/机巢选址文献里**没有系统做过**（检索确认：`humanitarian prepositioning dual use` 仅 1 条 NOFOMA 2023 社论，c=1）—— 这正是可以声称的空位。

## 三、完整模型骨架（可直接改写为论文 Model 章节）

$$\min\ \underbrace{\sum_j (f_j y_j + \gamma_{j k_j})}_{\text{建巢}} + \sum_{s\in S\cup\{0\}} p_s \Bigl[\underbrace{\sum_{j}c^{op}_j q_j}_{\text{平时运维}} + \underbrace{\sum_{i,j,t,m}c^{tr}_{ij}x^m_{ij,t,s}}_{\text{任务执行}} + \underbrace{\sum_j c^{conv}_j w_{j,s}}_{\text{平转急}} + \underbrace{\sum_{i,t}\pi^P u^P_{i,t} + \pi^E u^E_{i,t,s}}_{\text{未满足惩罚(量纲已统一)}}\Bigr]$$

约束：服务半径覆盖（R1/R2 差异化）→ 容量共享 (C1) → 转换逻辑 (C2) → 优先级配给 (C3) → 需求平衡与变量域。

**鲁棒升级（当 $p_s$ 不可靠时）**
- min-max 鲁棒：借 POM 2017（c=226，含"灾后预置库可用比例"的左端不确定 + 需求/路容的右端不确定，玉树地震案例）
- 风险规避 DRO：借 IJPR 2021（c=43，worst-case mean-CVaR，box/polyhedral 模糊集可等价转 MILP）

## 四、可迁移文献卡（a 项成果）

### ★ 卡片1（最贴 dual-use，优先精读）
**Integrating supply chains for emergencies and ongoing operations in UNHCR** — JOM 2016, c=98, doi:10.1016/j.jom.2016.05.009
- 问题：人道组织习惯把**应急供应链**和**日常运营供应链分开跑**；本文提"联合预置(joint prepositioning)"：同一套仓库网络同时服务应急响应与 ongoing operations
- 决策：仓库选址（并首次把可达性、共址、安全、人力等定性情境因子量化进网络优化）
- 结论：联合预置使全球仓网可扩张、成本下降、响应时间缩短
- **借到你这**：①"一个机巢网络同时服务平时任务 + 应急任务"的同构论证；②**"联合预置 vs 分离预置"的对比实验设计可直接照搬**（审稿人最爱看这种对照）；③定性因子的量化方法（把"空域管制/社区接受度"算进去）

### ★ 卡片2（两阶段骨架的标准来源）
**Stochastic Optimization for Natural Disaster Asset Prepositioning** — POM 2009, c=391, doi:10.1111/j.1937-5956.2009.01119.x
- 结构：两阶段随机；一阶段=预算分配到"容量与资源扩张"（仓库、带人员的医疗设施、停机坪、避难所）；二阶段=各情景下的调度（抢救待疏散人口、给留守人口送物资、转运流离人口）
- 目标：最小化**期望伤亡人数**（非成本！）
- **借到你这**：①把"机巢容量扩张"写成同类一阶段变量；②用**预算约束**作为平急之间的资源耦合通道；③示范"目标函数可以不是钱"—— 你要统一量纲时可以走"时间/伤亡/剥夺"口径

### ★ 卡片3（最短路径 + 可靠性 + 选址-路径合一）
**Location Routing Approach for the Humanitarian Prepositioning Problem** — TRR 2008, c=171, doi:10.3141/2089-03
- 结构：预置 = 选址 + 车辆路径联合；用**最可靠路径**处理运输网络中断；整数规划
- **借到你这**：①平时"巡检/配送路径"与应急"投送路径"写进同一 LRP，路径决策成为平急耦合通道；②"最可靠路径"对应你的**空域受限/航路中断/备降**问题（应急备降在你的关键词表里）；③中大规模网络可解（含算法效率论证）

### ★ 卡片4（目标函数统一的标准引用）
**On the appropriate objective function for post-disaster humanitarian logistics models** — JOM 2013, c=552, doi:10.1016/j.jom.2013.06.002（Holguín-Veras 等）
- 核心：提出**剥夺成本(deprivation cost)**，把未满足需求带来的痛苦货币化
- **借到你这**：解决"平时成本 vs 应急短缺"量纲不可加的硬伤；$\pi^E$ 的取值有了文献依据而非拍脑袋

## 五、审稿雷区（写作时自查）

1. **只用一个加权系数 λ 糊两个模态** → 必被问"λ 凭什么"。解法：ε-约束 + 帕累托前沿 / 给出 λ 的预算影子价格含义 / 用情景概率天然加权（R1）
2. **创新点=换皮**（把人道预置的"储备库"换成"机巢"） → 必须给出无人机**独有**的耦合：机巢-机队-任务三级容量耦合（巢位容量 ≠ 机队规模 ≠ 载荷/航时）、异巢起降、空域/航路约束、转换不是"开仓"而是"机队重配置（换电池/换载荷/航线上报）"
3. **情景集合拍脑袋（3 个假设情景）** → 用灾害数据（EM-DAT/历史灾情）生成情景族，或走 DRO 模糊集
4. **只做期望最优、无风险度量** → 应急侧加 CVaR/min-max，或加硬约束"响应时间 ≤ τ_E"兜底
5. **量纲不统一却直接相加** → R3（时间统一 或 剥夺成本货币统一）
