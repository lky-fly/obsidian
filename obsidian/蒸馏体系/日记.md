## APPKSA 2.0

### A — 目标（具体、量化、分主次）

**主目标：博三结束前（2028年6月前）拿到满意的算法岗offer**

"满意"的定义（量化标准）：

- 薪资：不低于XX万/年（根据行业基准自定）
- 技术栈：与博士研究方向强相关，非纯业务开发
- 地点：优先XX城市（或接受范围）

**支撑目标的三个子目标（按优先级排序）：**

| 优先级 | 子目标 | 量化标准 | 截止时间 |
| :----- | :----- | :------- | :------- |
|        |        |          |          |

| P0   | 学术产出  | 发表2篇A类论文（至少1篇一作）        | 2027年12月 |
| ---- | --------- | ------------------------------------ | ---------- |
| P1   | 项目/技术 | 完成1个可演示的核心项目，代码开源    | 2027年9月  |
| P2   | 身体状态  | BMI控制在正常范围，无持续性疲劳/疼痛 | 持续       |
| P3   | 人脉网络  | 认识5位以上目标领域从业者/前辈       | 2027年6月  |

------

### P — 问题（事实化、量化、因果链）

| 问题描述（事实层） | 与目标的因果链 |
| :----------------- | :------------- |
|                    |                |

| 日均有效科研时间约2.5小时，远低于博士应有的6-8小时           | 直接导致论文进度滞后，无法满足毕业和求职门槛       |
| ------------------------------------------------------------ | -------------------------------------------------- |
| 每周健身计划执行率约20%，近3个月体重上升X斤                  | 精力下降、久坐导致颈椎不适，影响长期可持续输出     |
| 读完论文后无输出（不写笔记/不复现代码），遗忘率>70%          | 看似"读了很多"，实则没有积累，无法转化为项目或论文 |
| 每天刷社交媒体（抖音/小红书）>1.5小时，其中科研相关内容占比<30% | 时间黑洞，制造"在学习"的幻觉，挤占深度工作时间     |
| 每周有3-4天晚上处于"迷茫/焦虑"状态，无实质产出               | 情绪内耗，进一步压缩有效时间，形成负循环           |

------

### P — 原则（两难时的决策依据）

1. **时间分配原则**：当子目标冲突时，按 P0 > P1 > P2 > P3 优先级执行；每日核心科研时间（9:00-12:00, 14:00-17:00）神圣不可侵犯，任何人/事不得占用。
2. **信息摄入原则**：科研信息以论文（arXiv/顶会）和官方文档为主，社交媒体仅作为"发现线索"的工具，发现后必须追溯到原始论文，单条信息流停留不超过10分钟。
3. **健康红线原则**：出现连续3天睡眠不足6小时或身体疼痛时，强制降低工作强度，优先恢复身体状态——健康崩溃会导致所有目标归零。
4. **输出倒逼输入原则**：每读一篇论文，必须产出至少一份笔记或一段可运行代码；没有输出的阅读等于没读。

------

### K — 关键点（抓手，与目标一一映射）

| 对应子目标 | 关键点 | 为什么是"关键" |
| :--------- | :----- | :------------- |
|            |        |                |

| P0 论文 | 确定创新方向并完成第一篇论文的实验验证 | 第一篇是破冰，有了第一篇才有第二篇的节奏         |
| ------- | -------------------------------------- | ------------------------------------------------ |
| P1 项目 | 选定一个核心算法模块，从0到1复现并改进 | 可演示的项目是面试时最有说服力的"作品"           |
| P2 身体 | 建立"最低限度运动"习惯（而非完美计划） | 从20%执行率到100%执行率，先求有再求好            |
| P3 人脉 | 每月主动发起1次与目标领域从业者的交流  | 人脉不是"认识多少人"，而是"有多少人知道你做什么" |

------

### S — 步骤（嵌入时间、频率、deadline）

**P0 论文推进：**

- 每周一上午：浏览arXiv/顶会最新论文，筛选2-3篇相关方向精读（2h）
- 每周三、五下午：专注实验/代码（3h×2）
- 每读完一篇论文：24小时内输出结构化笔记（Notion模板），否则标记为"无效阅读"
- 每月最后一个周日：回顾当月论文笔记，提炼可尝试的创新点

**P1 项目推进：**

- 9月底前：确定项目选题（与导师确认可行性）
- 10月-12月：核心模块开发与验证
- 2027年1月：代码整理+开源+写技术博客

**P2 身体管理：**

- 每天：晚饭后散步/拉伸 ≥20分钟（最低限度，不追求完美）
- 每周二、四、六：有氧运动30分钟（跑步/游泳/健身）
- 每周日晚：记录本周睡眠时长和身体状态

**P3 人脉拓展：**

- 每月第2周：通过导师/学长/会议等渠道，约1位目标领域从业者线上交流（30分钟）
- 交流前：准备3个具体问题；交流后：24小时内发送感谢邮件并附上个人简介

**心态管理：**

- 每天22:00-22:15：写"今日三件事"复盘（只记录客观完成度，不评判情绪）
- 每周日晚：用30分钟做周度APPKSA检视（对照目标检查偏差）

------

### A — 注意事项（风险预案+反思框架）

**1. 防"贪多嚼不烂"预案：**

- 同时进行的"深度任务"不超过2个（当前=论文+项目）
- 新增任何任务前，必须先回答：这件事替换掉现有哪个任务？如果替换不掉，就不做。

**2. 防"完美主义导致拖延"预案：**

- 论文笔记先写"粗糙版"再迭代，不允许"等想清楚了再写"
- 运动先完成"最低限度"（20分钟散步），状态好再加量，状态不好也不归零

**3. 每日反思框架（3个问题，5分钟）：**

- 今天核心科研时间有几小时？（事实）
- 今天有没有产出？（笔记/代码/文字都算）
- 今天最大的时间黑洞是什么？（明天如何规避）

**4. 周度纠偏机制：**

- 如果连续2周论文进度低于计划的60%，触发"选题/方法复盘"——与导师深度讨论一次，判断是否方向有误或难度过高
- 如果连续2周运动执行率低于50%，降低运动门槛（如从30分钟降到15分钟），先保住习惯再谈强度

**5. 社交媒体隔离：**

- 抖音/小红书仅在"发现论文线索"时使用，且必须设置15分钟闹钟
- 禁止在核心科研时间段（9:00-12:00, 14:00-17:00）打开任何社交媒体

缺点：这个版本的核心变化是：**每个环节都尽量从"感受"变成了"数字"，从"口号"变成了"动作"，从"愿望"变成了"日程"**
