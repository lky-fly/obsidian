# 论文AI审稿/润色Prompt体系

> 来源：13个论文润色Prompt的蒸馏整理

## 一、整体分类

| 类别 | 包含Prompt | 用途 |
|------|-----------|------|
| 综合润色 | 01, 05, 13 | 全文/段落的整体提升 |
| 去AI味 | 02, 08 | 消除AI痕迹和中式英语 |
| 逻辑强化 | 03 | 因果链、论证递进 |
| 深度分析 | 04, 07 | 机理/机制/讨论深化 |
| 审稿模式 | 06, 12 | 审稿人视角 + 回复润色 |
| 句式/摘要 | 10, 11 | 句式多样化 + 摘要特化 |
| 创新表达 | 09 | 不浮夸地强调创新性 |

## 二、各Prompt核心指令拆解

### 01 - 综合润色（万能主Prompt）

**角色定位：** Nature高级科学编辑

**核心指令：**
- 提升科学精确性
- 改善逻辑连贯性
- 优化句子节奏
- 增加学术成熟度
- 消除AI味措辞
- 去除冗余和夸大
- 修正弱过渡
- 保持技术准确性
- 简洁、权威、可发表
- 优先清晰度和机理深度

### 02 - 去AI味（顶刊核心）

**目标：** 让文字像有经验的本土研究者写的

**具体操作：**
- 避免AI常用词汇
- 避免重复的句子开头
- 避免过度使用分词结构
- 避免人为平滑的过渡
- 引入自然的句法和论证变化

### 03 - 强化逻辑链

**链条要素：** 因果关系 -> 过渡逻辑 -> 实验观察 -> 科学结论

**要求：** 每句话自然引出下一句，论证递进清晰

### 04 - 机制分析升级

**Nature最看重的维度：**
- 构效关系（Structure-Property Relationship）
- 热力学/动力学起源
- 界面演化
- 物化机制

**目标：** 不只是描述现象，要解释机理

### 05 - Nature风格

**强调三要素：**
1. 科学重要性（Scientific Significance）
2. 前瞻性影响（Forward-looking Impact）
3. 领域范围的相关性（Field-wide Relevance）

**红线：** 保持严谨学术语气，避免炒作（hype）

### 06 - 审稿人模式

**角色：** Nature Materials的苛刻审稿人

**检查清单：**
- 模糊表述（Vague statements）
- 无证据的断言（Unsupported claims）
- 逻辑跳跃（Logical jumps）
- 证据不足（Insufficient evidence）
- 过度解读（Overinterpretation）

### 07 - 提升Discussion层次

**从"描述数据"升级到"解读科学"：**
- 摒弃重复描述数据
- 聚焦机理见解（Mechanistic Insights）
- 与已有文献对比
- 指出局限性
- 拓展更广泛的意义

### 08 - 消除中式英语

**操作：**
- 纠正直译结构
- 用符合顶刊习惯的惯用表达
- 用idiomatic academic English替代rigid structures

### 09 - 强化创新性表达

**关键：** 不浮夸、不推销

**核心问题：** 这项工作在机理、方法或性能上**从根本上**与已有研究有什么不同？

### 10 - 高级句式优化

**三个维度：**
1. 句子长度变化（短-长-短交错）
2. 句法结构变化（主谓宾-从句-分词等）
3. 修辞节奏变化（强调-平缓-强调）

### 11 - 摘要终极润色

**摘要的5个必须整合的要素：**
1. Motivation（动机）
2. Methodology（方法）
3. Key Findings（关键发现）
4. Mechanism（机理）
5. Significance（意义）

### 12 - 审稿回复润色

**语气要求：** 专业、自信、有科学说服力

**保持礼貌的同时：**
- 强化逻辑
- 加强证据
- 提高可信度

### 13 - 终极组合Prompt

**三重角色同时扮演：**
1. Nature编辑 -> 写作标准
2. 领域资深研究者 -> 科学深度
3. 苛刻审稿人 -> 批判性

**提升维度：** 逻辑连贯性、机理深度、科学精确性、叙事流畅性、学术成熟度

## 三、论文润色"六步法"（基于上述Prompt提炼）

```
第1步：综合润色（01/05/13）
  -> 整体过一遍，解决基础问题

第2步：去AI味 + 消除中式英语（02/08）
  -> 让文章读起来像人写的

第3步：强化逻辑链（03）
  -> 每段的因果递进是否清晰？

第4步：深化机理/提升讨论（04/07）
  -> 从"描述了啥"到"解释了为啥"

第5步：审稿人自检（06）
  -> 用审稿人视角挑毛病

第6步：句式优化 + 摘要特润（10/11）
  -> 最后打磨语言和摘要
```
