# 论文规范标准清单

> 基于审稿意见和写作经验提炼的论文写作规范

## 一、论文写作"六步润色法"

参见「AI论文润色Prompt体系.md」笔记。

标准流程：
1. 综合润色（基础问题）
2. 去AI味 + 消除中式英语
3. 强化逻辑链
4. 深化机理/提升讨论
5. 审稿人自检
6. 句式优化 + 摘要特润

## 二、审稿人检查清单（06）

论文写完后对照检查：
- [ ] 是否有模糊表述？
- [ ] 是否有无证据支撑的断言？
- [ ] 是否存在逻辑跳跃？
- [ ] 证据是否充分？
- [ ] 是否过度解读结果？

## 三、Nature风格三要素

1. Scientific Significance — 科学重要性
2. Forward-looking Impact — 前瞻性影响
3. Field-wide Relevance — 领域相关性

## 四、摘要五要素

1. Motivation — 研究动机
2. Methodology — 研究方法
3. Key Findings — 关键发现
4. Mechanism — 作用机理
5. Significance — 科学意义

## 五、讨论（Discussion）写作规范

不应只是：
- 重复描述数据

而应聚焦：
- 机理见解（Mechanistic Insights）
- 与已有文献对比
- 指出局限性
- 拓展更广泛的意义
