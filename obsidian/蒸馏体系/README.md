# 📚 科研写作蒸馏笔记体系

## 体系结构

```
蒸馏体系/
├── README.md                    ← 本文件（体系说明）
│
├── 论文写作蒸馏/                 ← 论文写作技巧提炼
│   ├── 写作架构.md               ← 论文各部分写作架构总结
│   ├── 写作风格与句式.md          ← 常用句式、衔接、风格
│   ├── 各学科特色.md              ← 不同学科的写作差异
│   └── 已分析论文清单.md          ← 已蒸馏分析的论文列表
│
├── 国自然本子蒸馏/               ← 国自然申请书写作
│   ├── 立项依据写法.md            ← 立项依据的架构与套路
│   ├── 研究方案设计.md            ← 研究内容与方案写法
│   ├── 创新点提炼.md              ← 创新点的表述方式
│   ├── 预算与团队.md              ← 预算编制与团队介绍
│   └── 已分析本子清单.md          ← 已分析的本子列表
│
├── 论文规范标准/                 ← 审稿意见→规范体系
│   ├── 常见审稿意见.md            ← 各类型审稿意见汇总
│   ├── 论文规范标准清单.md        ← 从审稿意见提炼的标准
│   ├── 写作红线.md                ← 不能犯的致命错误
│   └── 投稿策略总结.md            ← 期刊选择与回复策略
│
└── 素材暂存区/                   ← 待蒸馏的原始材料
    └── README.md
```
