# FITEE 格式审查 Checklist

> 每次提交前逐项自查，不得跳过任何行。

---

## 🏠 首页信息

- [ ] **标题**：仅首词大写，其余非专有名词小写；冒号后首字母小写
- [ ] **作者姓**：全大写（`Guohao YUAN`）
- [ ] **作者名**：两个字直接连接，不空格不加连字符
- [ ] **单位**：斜体；城市与邮编之间无标点
- [ ] **日期**：月份缩写正确（`Sept.`/`Jan.`/`Feb.`等）；日期不加前导 0
- [ ] **DOI**：格式 `https://doi.org/10.1631/ENG.ITEE.xxxx.xxxx`
- [ ] **关键词**：分号分隔；首词大写其余小写；末尾无标点
- [ ] **`\shortauthor`**：已定义且编译不报错（未定义则删掉）
- [ ] **脚注标识**：通信作者 `\ddagger`、邮箱 `\dagger`、ESM `#`、基金 `*`
- [ ] **邮箱**：顺序与作者顺序对应；全部提供时去掉标识符
- [ ] **基金**：格式 `Project supported by ... (Nos. xxx, xxx, and xxx)`
- [ ] **ORCID**：一作和通信作者即可
- [ ] **版权声明**：已添加

---

## 📐 章节格式

- [ ] **结论标题**：`Conclusions`（复数）
- [ ] **Acknowledgments**：已添加（基金致谢）
- [ ] **Conflict of interest**：已添加
- [ ] **Data availability**：已添加
- [ ] **Contributors**：已添加
- [ ] **AI 声明**：已添加
- [ ] **所有节/子节标题**：仅首词大写，其余非专有名词小写
- [ ] **算法 Caption**：首词大写规则同样适用

---

## 🖼️ 图表

- [ ] **图片格式**：全部为 `.eps`（无 `.png`/`.jpg`/`.pdf`）
- [ ] **图内字体**：Arial，文字 7pt，图例 6pt，子图序号 8pt
- [ ] **线宽**：0.75pt
- [ ] **图例**：无边框，背景透明
- [ ] **子图序号**：水平方向；图中只保留 `(a)` `(b)`，说明移到整体 caption
- [ ] **图题**：句末无句号；粗体；不以 `the` 开头
- [ ] **文内引用**：`Fig. 3a` / `Figs. 3a and 3b`（字母不加括号）
- [ ] **表格格式**：三线表（仅 `\toprule`/`\midrule`/`\bottomrule`，无 `\hline`/`\cline`）
- [ ] **表格尺寸**：通栏 18cm，单栏 7.95cm
- [ ] **表头**：白体居中（不加粗）
- [ ] **表注**：`\footnotesize`（7pt），末尾无标点
- [ ] **跨线**：用 `\cmidrule` 而非 `\cline`
- [ ] **数字格式**：五位以上每三位加 `~`；小数位数一致
- [ ] **浮动体定位**：禁用 `[H]`，用 `[ht!]` 或 `[t]`
- [ ] **`\vspace` 在浮动体前**：无（改为 `\setlength{\textfloatsep}{}`）

---

## 📐 公式

- [ ] **变量速判**：过一遍"三问法"（单字母？函数？加粗？）
- [ ] **多字母缩略词**：100% `\mathrm{}`（MAE, RMSE, Gbps）
- [ ] **e/π/d/j**：100% 正体 `\mathrm{e}` 等
- [ ] **下标单词缩写**：100% `_{\mathrm{pre}}` 等（不是 `_{pre}`）
- [ ] **单字母变量下标**：斜体 `f_{t}`（不是 `f_{\text{t}}`）
- [ ] **矩阵/矢量**：`\bm{}` 粗斜体（人工审查）
- [ ] **数学期望**：`\mathbb{E}` 空心正体
- [ ] **公式末尾标点**：接 where → 逗号；接新句 → 句号
- [ ] **公式引用**：`Eq. (1)` / `Eqs. (1) and (2)` / `Eqs. (1)–(5)`
- [ ] **公式编号**：数字必须加括号

---

## 📚 参考文献

- [ ] **排序**：一作姓氏 A→Z；同姓时按作者数（少→多）→年份
- [ ] **正文引用**：`\cite`（主语）/ `\citep`（括号）
- [ ] **作者数格式**：1人 `Chen (2023)`；2人 `Chen and Zhang (2023)`；≥3人 `Chen et al. (2023)`
- [ ] **一作同姓区分**：加名字缩写 `Li JX et al.` vs `Li JZ et al.`
- [ ] **论文标题大小写**：仅首词大写
- [ ] **DOI/URL**：末尾无句号；不用反引号
- [ ] **会议名**：正体（不用 `{\em ...}`）
- [ ] **会议序数词**：上标正体 `54^{\mathrm{th}}`
- [ ] **会议名缩写**：`Parallel`→`Parall.`、`Distributed`→`Distrib.`、`Processing`→`Process.`
- [ ] **栏末平衡**：`\balance` 在 `\begin{thebibliography}` 之前

---

## ⚠️ 正文禁止

- [ ] **无 `enumerate`/`itemize` 列表环境**（改为 `1.~... 2.~...`）
- [ ] **无 `\mbox{}` 防换行**（正文段落中）
- [ ] **无 `\usepackage{lmodern}`**（会覆盖 Arial）
- [ ] **无重复 `\usepackage[T1]{fontenc}`**（fitee.sty 已自带）
- [ ] **无重复 `\makeatletter`/`\small`/`\usepackage`**
- [ ] **无 `breaklinks=true`**（与 dvips 不兼容）

---

## 📋 最终确认

- [ ] 编译通过（dvips 链）
- [ ] 所有引用交叉检查（无 dangling reference）
- [ ] PDF 预览逐页检查排版
- [ ] 所有图片正常显示（无 missing .eps）
- [ ] 中英文摘要、关键词完整
