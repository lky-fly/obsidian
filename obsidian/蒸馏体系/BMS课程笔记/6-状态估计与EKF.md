# 状态估计 — SOC与扩展卡尔曼滤波

> 来源：Model-based BMS Course (Davide M. Raimondo), p199-p216

---

## 为什么需要状态估计（p199）

电池的关键状态（SOC、SOH、内部温度）不能直接通过传感器测量，必须通过模型+观测器进行估计。

## 为什么用扩展卡尔曼滤波（EKF, p200）

- 电池模型是**非线性**的（OCV-SOC非线性、RC动态非线性）
- 线性卡尔曼滤波（KF）只能用于线性系统
- EKF通过对非线性函数进行**一阶泰勒展开（雅可比矩阵）**实现线性化

## EKF通用框架（p201-p202）

### 离散时间非线性系统

```
状态方程：
  xk = f(xk-1, uk-1) + wk-1
测量方程：
  yk = h(xk, uk) + vk
```

其中：
- **xk**：状态向量（如 [SOC, V1, V2]）
- **uk**：输入（电流 Iapp）
- **yk**：测量（端电压 Vt）
- **wk**：过程噪声，协方差 Q
- **vk**：测量噪声，协方差 R

### EKF预测与校正（p202）

**预测步骤（时间更新）**：
```
x̂k|k-1 = f(x̂k-1|k-1, uk-1)
Pk|k-1 = Ak * Pk-1|k-1 * Ak^T + Q
```

**校正步骤（测量更新）**：
```
Kk = Pk|k-1 * Ck^T * (Ck * Pk|k-1 * Ck^T + R)^(-1)
x̂k|k = x̂k|k-1 + Kk * (yk - h(x̂k|k-1, uk))
Pk|k = (I - Kk * Ck) * Pk|k-1
```

其中 **Ak** 和 **Ck** 是雅可比矩阵：
- Ak = ∂f/∂x | x̂k-1|k-1
- Ck = ∂h/∂x | x̂k|k-1

## Q和R的解释（p203）

| 参数 | 含义 | 取值影响 |
|------|------|---------|
| **Q（过程噪声协方差）** | 模型不确定度 | Q越大→更相信测量值→更快的动态响应，但更易受噪声干扰 |
| **R（测量噪声协方差）** | 传感器不确定度 | R越大→更相信模型→更平滑的估计，但响应变慢 |

**调参经验**：Q和R的比值（Q/R）决定了滤波器的响应速度与噪声抑制的平衡。

## 电池ECM（一阶RC）的EKF实现（p205-p207）

### 离散化ECM模型

**状态向量**：x = [SOC, V1]

**连续时间模型**：
```
ṠoC = -Iapp / Qn
V̇1 = -V1/(R1*C1) + Iapp/C1
```

**离散化（一阶欧拉法，Δt为采样时间）**：
```
SOC[k+1] = SOC[k] - (Δt/Qn) * Iapp[k]
V1[k+1] = (1 - Δt/(R1*C1)) * V1[k] + (Δt/C1) * Iapp[k]
```

**测量方程**：
```
Vt[k] = Vocv(SOC[k]) + V1[k] + R0 * Iapp[k]
```

### 雅可比矩阵（p207）

**状态转移雅可比 Ak**：
```
Ak = [1,       0;
     0,  1 - Δt/(R1*C1)]
```

**测量雅可比 Ck**：
```
Ck = [dVocv/dSOC | SOĈk|k-1,  1]
```

其中 dVocv/dSOC 从OCV-SOC曲线计算，可以通过查表+插值实现。

## 可观测性分析（p208）

对于一阶RC模型 + SOC估计，可观测性取决于：
1. **输入是否持续激励**：电流必须变化才能使所有状态可观
2. **零电流时**：V1的衰减由时间常数τ=R1*C1决定，SOC变化由Qn决定
3. **Vocv(SOC)的斜率**：在OCV平缓区域（如LFP的中段），SOC的可观测性降低

## EKF vs 其他方法的优势（p209）

| 方法 | 优点 | 缺点 |
|------|------|------|
| **安时积分（Coulomb Counting）** | 简单、计算量小 | 误差累积，需初始值 |
| **开路电压法（OCV Lookup）** | 精度高（静止时） | 需要长时间静置 |
| **EKF** | 在线实时估计、抗噪声、融合模型+测量 | 需模型准确、调参复杂 |
| **UKF** | 非线性处理更精确 | 计算量更大 |

## SOC精度的重要性（p215-p216）

SOC估计误差会导致：
- 可用容量误判 → 里程焦虑或过度放电
- 充电策略错误 → 过充/欠充
- 功率能力误判 → 安全隐患
- SOH计算偏差 → 寿命误判
