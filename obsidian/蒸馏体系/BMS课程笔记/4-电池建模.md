## 电池模型分类

```
电池模型
├── 等效电路模型 (ECM) — 经验模型，基于电路元件
│   ├── Rint模型（内阻模型）
│   ├── Thevenin模型（一阶RC）
│   ├── PNGV模型
│   └── DP模型（双极化/二阶RC）
└── 电化学模型 (EM) — 物理模型，基于PDE
    └── P2D模型（伪二维模型）
```

**模型选择准则**（p87）：取决于用途——**仿真用P2D，控制用ECM**。

## P2D电化学模型（p89-p90）

**Pseudo Two-Dimensional (P2D) 模型**是锂离子电池最广泛使用的电化学模型。

- 由 Doyle, Fuller, Newman (1993, JES) 提出
- 描述：一组紧耦合、高度非线性的偏微分代数方程 (PDAEs)
- 定义：质量守恒和电荷守恒
- 计算复杂度高，不适合实时BMS

## 等效电路模型（ECM, p101-p108）

### 1. Rint模型（内阻模型, p102）

最简单的ECM，仅含开路电压源 + 串联内阻：

```
Vt = Vocv + R0 * Iapp
```

- **Vt**：端电压
- **Vocv**：开路电压
- **R0**：欧姆内阻
- **Iapp**：负载电流（放电为正）

**局限性**：无法模拟电池的瞬态响应（极化效应）。

### 2. Thevenin模型（一阶RC, p104）

在Rint模型基础上增加一个RC网络模拟极化效应：

```
ṠoC = 1/Qn * Iapp
Vt = Vocv(SOC) + V1 + R0 * Iapp
dV1/dt = -V1/(R1*C1) + Iapp/C1
```

- **R1, C1**：极化电阻和电容，表征电化学极化
- **τ = R1*C1**：时间常数
- **V1**：极化电压

### 3. PNGV模型（p105）

在Thevenin基础上增加开路电压电容（模拟OCV随SOC的变化）：

```
dVocv/dt = Iapp/Cocv  (Cocv为OCV电容)
```

### 4. DP模型（双极化/二阶RC, p106-p107）

两个RC网络串联，分别模拟**短时间常数**和**长时间常数**的极化过程：

```
dV1/dt = -V1/(R1*C1) + Iapp/C1
dV2/dt = -V2/(R2*C2) + Iapp/C2
ṠoC = Iapp/Qn
Vt = Vocv(SOC) + V1 + V2 + R0 * Iapp
```

- **R1, C1**：电化学极化（快动态，τ短）
- **R2, C2**：浓差极化（慢动态，τ长）
- 比一阶RC模型更精确地描述瞬态响应

### 模型精度提升（p107）

所有ECM的参数（R0, R1, C1, R2, C2）可以设为SOC、温度(T)和SOH的函数：
- `R0 = R0(SOC, T, SOH)`
- `R1 = R1(SOC, T, SOH)`
- `Vocv = Vocv(SOC)` — 这是最基本的相关性

## 模型对比总结

| 模型 | 参数数 | 精度 | 计算量 | 适用场景 |
|------|--------|------|--------|---------|
| Rint | 1+R | ★☆ | 极低 | 简单功率计算 |
| Thevenin (1RC) | 3+R | ★★★ | 低 | SOC估计、实时BMS |
| PNGV | 4+R | ★★★ | 低 | 含OCV动态的场景 |
| DP (2RC) | 5+R | ★★★★ | 中 | 高精度SOC/SOH估计 |
| P2D | >30 | ★★★★★ | 极高 | 离线仿真、设计优化 |
