# 论文写作架构总结

> 基于吴肖龙博士学位论文 + Applied Energy期刊论文蒸馏

## 一、博士论文架构（6章标准结构）

```
第1章 绪论（背景->现状->不足->研究内容）
第2章 方法/建模（理论框架->模型建立->仿真分析）
第3章 实验/验证（实验配置->结果分析->方法验证）
第4章 进一步研究（深入分析->方法提出->实例验证）
第5章 综合应用（集成方法->系统验证->效果评估）
第6章 总结与展望
```

### 每章的闭环结构
每章统一采用：引言 -> 理论/方法 -> 实验/仿真 -> 结果分析 -> 本章小结

---

## 二、期刊论文架构（IMRaD变体）

```
Introduction（漏斗式：宽->窄->缺口->本研究）
Model development（几何/控制方程/边界条件/网格/验证）
Results and Discussion（温度->流动->电特性递进）
Conclusion（极简，每条量化）
```

---

## 三、博士论文绪论写法

### "金字塔"组织法
```
产业背景（宽）-> 学术现状（中）-> 具体方向（窄）-> 研究不足（聚焦）
```

### 文献综述的六维度覆盖
1. 建模与分析（电堆建模/系统建模）
2. 实验分析（电堆实验/系统实验）
3. 性能预测（寿命预测方法）
4. 故障诊断（积碳/电堆/系统级）
5. 健康管控（电堆控制/系统控制）

### 不足提炼（4个核心不足）
每个用黑体小标题突出，源自文献综述的推导

### 经典句式
- "若要获得定量、准确和全面的系统评价必须采用XXX"（从综述推导方法论）
- "综合上述文献，发现现有的研究鲜有XXX"（总结不足）

## 四、英文论文分析注意要点

蒸馏英文论文时需额外分析：
1. **高频词汇统计**：统计研究动词、连接词、技术名词的词频
2. **动词搭配**：总结描述研究、发现、效果、对比的常用动词搭配
3. **词汇升级**：提供初级词到高级学术词的替换建议（show->demonstrate等）
4. **连接词使用**：统计however/therefore/thus等连接词的使用频率和位置
5. **句式模板**：提取可复用的学术句式模板

具体词汇统计示例见「英文学术高频词汇.md」笔记。

## 五、燃料电池/能源系统博士论文通用架构

基于吴肖龙（SOFC）+ 李曦（PEMFC）两篇博士论文对比：

### 共性结构
```
第1章 绪论（背景->现状->不足->本文工作）
第2章 系统建模/电特性分析（机理模型+参数分析）
第3章 系统模型/方法（集总建模/子系统建模）
第4章 控制策略/应用方法（算法设计+仿真验证）
第5章 总结与展望
```

### 共性特征
- 每章设"引言"和"本章小结"形成闭环
- "建模+控制+仿真验证"三合一范式
- 对称比较框架（两种方法对比，说明优劣）
- 公式-表格-图形三位一体论证
- 双重总结机制（各章小结+全文总结）

### SOFC vs PEMFC差异

| 维度 | SOFC（高温） | PEMFC（低温） |
|------|------------|--------------|
| 工作温度 | 600-1000°C | 60-80°C |
| 建模重点 | 温度分布、热管理 | 水管理、气压控制 |
| 燃料 | 天然气/生物质气 | 高纯氢气 |
| 控制目标 | 热管理、故障诊断 | 温压控制、水热平衡 |
| 应用 | 固定电站 | 交通/便携电源 |

## 七、李爽红博士论文架构（2026-07-01蒸馏，1篇）

### 7.1 论文类型与架构总览

**类型：方法论驱动的英文博士论文**（控制科学与工程，上交大，2018年6月）

**整体结构**：8章递进式，核心为"基础→理论框架→四重应用→结论"

```
Ch1 Introduction (p1-13)
  └─ 1.1 Background → 1.2 Literature Review → 1.3 Research Status
  └─ 1.4 Fault Tolerant Control → 1.5 Existing Problems → 1.6 Organization

Ch2 Mathematical Preliminaries (p14-25)
  └─ 2.1 Tensor Fundamentals → 2.2 Supervised Learning → 2.3 SOFC System

Ch3 Tensor Label Learning Framework (p26-47) ← 理论核心章
  └─ 3.2 0~3+ Order Tensor Labels → 3.3 Fault Location → 3.4 Joint Learning → 3.5 FTC

Ch4 Simultaneous Fault Identification (p48-67)
  └─ 1-order TLL应用：PCA + Multi-label SVM

Ch5 Transfer Learning for Simultaneous Fault (p68-87)
  └─ ML-Transfer Learning: RF single→simultaneous fine-tuning

Ch6 Fault Location via Feature Selection (p88-111)
  └─ 2-order TLL应用：mRMR-ReliefF + RF Variable Importance

Ch7 Fault Tolerant Control (p112-152)
  └─ 0-order TLL应用：PID decoupling + TS-BL-GPC online adaptive FTC

Ch8 Conclusions and Future Work (p153-154)
```

### 7.2 架构关键特征

1. **理论-应用对应映射**：Ch3 提出统一框架（0阶~3阶标签），Ch4-7 各章对应框架的不同阶数应用，体现了极强的前后呼应

2. **章节间递进逻辑**：
   - Ch4: 最简单（1阶识别）→ Ch5: 增加数据稀缺性约束（迁移学习）
   - Ch6: 增加维度（识别+定位=2阶）→ Ch7: 最复杂（识别+定位+控制全闭环）

3. **每章闭环结构**：引言→方法→算法→实验→讨论→小结（"Equation Section (Next)" 标记每章起始）

4. **实验验证的四段循环**（每章内重复）：
   ```
   实验设置(Table: 参数、数据量、评估指标)
     → 实验结果(Fig: 可视化 + Table: 定量对比)
     → 定性讨论（物理含义+工程启示）
     → 章末小结（一句话总结）
   ```

### 7.3 篇幅分配

| 章节 | 页数 | 占比 | 功能定位 |
|------|------|------|----------|
| Ch1 Introduction | 13 | 8.7% | 研究背景+文献综述+问题提炼 |
| Ch2 Preliminaries | 12 | 8.0% | 张量数学基础+SOFC实验平台 |
| **Ch3 Framework** | **22** | **14.7%** | **理论创新核心** |
| Ch4 Identification | 20 | 13.3% | 并发故障识别（1阶应用） |
| Ch5 Transfer Learning | 20 | 13.3% | 数据稀缺问题（迁移学习） |
| Ch6 Location | 24 | 16.0% | 故障定位（2阶应用） |
| Ch7 FTC | 41 | 27.3% | 容错控制（实验最重章） |
| Ch8 Conclusion | 2 | 1.3% | 过于简略 |

### 7.4 架构设计的可迁移模式

**"框架提出型"博士论文的标准组织逻辑**：
```
Ch2: 数学预备知识（张量计算、监督学习形式化、实验平台）
  ↓ "一切定义在此章完成"
Ch3: 提出框架（0~3+阶标签的统一形式化 + 性能度量推广）
  ↓ "框架提出后，逐阶展示应用"
Ch4: 最简单的阶（1阶识别）
Ch5: 增加复杂度（迁移学习）
Ch6: 增加维度（识别+定位=2阶）
Ch7: 最复杂（全闭环容错控制）
  ↓
Ch8: 收束（回顾贡献+展望）
```

### 7.5 与吴肖龙论文架构对比

| 维度 | 李爽红（2018, SJTU） | 吴肖龙（SOFC博士论文） |
|------|----------------------|------------------------|
| 章数 | 8章 | 6章 |
| 核心驱动 | 方法论（TLL框架） | 系统建模+实验 |
| 每章结构 | 引言→方法→算法→实验→小结 | 引言→理论/方法→实验/仿真→结果分析→本章小结 |
| 理论章位置 | Ch3（第3章，占15%） | Ch2（第2章） |
| 实验最重章 | Ch7（41页，占27%） | Ch5（综合应用章） |
| 结论长度 | 2页（偏短） | 完整总结+展望 |
| 公式密度 | 高（~50个编号公式） | 中高 |
| 图表密度 | 高（80+张图，30+张表） | 高（~75图23表） |

## 四、张涛论文架构（2026-06-01分析，6篇）

### 4.1 论文类型分布

| 类型 | 代表论文 | 架构模式 |
|------|---------|---------|
| 理论建模+数值仿真 | k/N系统维修策略分析、AOPN维修保障建模 | IMRaD变体，模型定义占40%+ |
| 方法研究+实验验证 | 考虑无线充电的无人机路径在线规划 | 引言→建模→方法→实验→结论，实验占比最大(~30%) |
| 综述+框架设计+案例 | 面向能源互联网的EMS研究 | 混合型：综述→框架提出→技术分析→案例验证 |
| 观点/问题-对策型 | 能源互联网在军事能源转型中的作用 | 背景→概念→问题→对策→结论 |
| 教改论文 | 军队工程硕士研究生培养 | 现状→问题→对策三段式 |

### 4.2 引言四种模式

| 模式 | 结构 | 代表论文 |
|------|------|---------|
| 漏斗式（从大到小） | 大背景→具体问题→文献综述→gap→贡献 | 无人机路径规划、面向能源互联网EMS |
| 递进式批评 | 一般方法(缺点)→改进A(不足)→改进B(仍有不足)→本文方案 | AOPN维修保障建模 |
| 问题驱动 | 宏大背景→问题聚焦→概念引出 | 能源互联网军事转型 |
| 直接切入 | 背景→问题→本研究 | 军队工程硕士研究生培养 |

### 4.3 实验对比四层递进（DRL论文标准范式）

```
第1层：方法内对比（贪心 vs 采样 vs 波束搜索）
第2层：同类型方法对比（DRL vs Pointer Network）
第3层：传统方法对比（DRL vs PSO/ACO/ALNS）
第4层：跨规模趋势（50→100→150→200节点）
```

### 4.4 五种结论模式

| 模式 | 结构 | 代表论文 |
|------|------|---------|
| 两段式（贡献+展望） | 1句贡献 + 1句优势 + 未来工作 | 无人机路径规划 |
| 两段式（贡献+未来） | 贡献总结+未来展望，不重复摘要 | 面向能源互联网EMS |
| 极简型 | 仅1句"做了什么+为什么重要" | AOPN、k/N系统 |
| "回环"收束式 | 历史回顾→趋势判断→定位重申→建议 | 能源互联网军事转型 |
| 三段式 | 回顾→总结→升华 | 军队工程硕士研究生培养 |
