# 论文写作架构总结

> 基于吴肖龙博士学位论文 + Applied Energy期刊论文蒸馏

## 一、博士论文架构（6章标准结构）

```
第1章 绪论（背景->现状->不足->研究内容）
第2章 方法/建模（理论框架->模型建立->仿真分析）
第3章 实验/验证（实验配置->结果分析->方法验证）
第4章 进一步研究（深入分析->方法提出->实例验证）
第5章 综合应用（集成方法->系统验证->效果评估）
第6章 总结与展望
```

### 每章的闭环结构
每章统一采用：引言 -> 理论/方法 -> 实验/仿真 -> 结果分析 -> 本章小结

---

## 二、期刊论文架构（IMRaD变体）

```
Introduction（漏斗式：宽->窄->缺口->本研究）
Model development（几何/控制方程/边界条件/网格/验证）
Results and Discussion（温度->流动->电特性递进）
Conclusion（极简，每条量化）
```

## 三、博士论文绪论写法

### "金字塔"组织法
```
产业背景（宽）-> 学术现状（中）-> 具体方向（窄）-> 研究不足（聚焦）
```

### 文献综述的六维度覆盖
1. 建模与分析（电堆建模/系统建模）
2. 实验分析（电堆实验/系统实验）
3. 性能预测（寿命预测方法）
4. 故障诊断（积碳/电堆/系统级）
5. 健康管控（电堆控制/系统控制）

### 不足提炼（4个核心不足）
每个用黑体小标题突出，源自文献综述的推导

### 经典句式
- "若要获得定量、准确和全面的系统评价必须采用XXX"（从综述推导方法论）
- "综合上述文献，发现现有的研究鲜有XXX"（总结不足）

## 四、英文论文分析注意要点

蒸馏英文论文时需额外分析：
1. **高频词汇统计**：统计研究动词、连接词、技术名词的词频
2. **动词搭配**：总结描述研究、发现、效果、对比的常用动词搭配
3. **词汇升级**：提供初级词到高级学术词的替换建议（show->demonstrate等）
4. **连接词使用**：统计however/therefore/thus等连接词的使用频率和位置
5. **句式模板**：提取可复用的学术句式模板

具体词汇统计示例见「英文学术高频词汇.md」笔记。

## 五、燃料电池/能源系统博士论文通用架构

基于吴肖龙（SOFC）+ 李曦（PEMFC）两篇博士论文对比：

### 共性结构
```
第1章 绪论（背景->现状->不足->本文工作）
第2章 系统建模/电特性分析（机理模型+参数分析）
第3章 系统模型/方法（集总建模/子系统建模）
第4章 控制策略/应用方法（算法设计+仿真验证）
第5章 总结与展望
```

### 共性特征
- 每章设"引言"和"本章小结"形成闭环
- "建模+控制+仿真验证"三合一范式
- 对称比较框架（两种方法对比，说明优劣）
- 公式-表格-图形三位一体论证
- 双重总结机制（各章小结+全文总结）

### SOFC vs PEMFC差异

| 维度 | SOFC（高温） | PEMFC（低温） |
|------|------------|--------------|
| 工作温度 | 600-1000°C | 60-80°C |
| 建模重点 | 温度分布、热管理 | 水管理、气压控制 |
| 燃料 | 天然气/生物质气 | 高纯氢气 |
| 控制目标 | 热管理、故障诊断 | 温压控制、水热平衡 |
| 应用 | 固定电站 | 交通/便携电源 |

## 六、吴肖龙写作架构专题（2026-06-01蒸馏）

### 6.1 四篇论文的架构总览

| 论文类型 | 架构模式 | 核心逻辑链 |
|---------|---------|-----------|
| 教学实验平台建设（中文） | 引言(四段) -> 实验装置描述 -> 实验步骤 -> 实验结果 -> 结论 | 背景→不足→平台→数据→育人 |
| 博士论文（179页） | 六章递进：绪论->建模->预报->检测->管控->展望 | 机理建模→状态预报→故障诊断→健康管控 |
| 故障仿真对比（英文） | 引言->系统描述->故障模型->仿真结果->讨论->结论 | 系统分解→故障注入→仿真对比→规律总结 |
| 教学改革（OBE-CDIO） | 引言->理论基础->总体框架->方案设计->评价体系->结语 | 政策需求→理论框架→方案设计→能力评价 |

### 6.2 教学实验平台建设论文架构（实验室研究与探索风格）

**六段标准结构：**

```
章0 摘要（四句：做了什么→由什么构成→研究了什么→育人价值）
章0 引言（背景→现实困境→已有方案不足→亟须建设）
章1 实验设计/装置描述（总体构成→子系统详解→工作原理）
章2.1 实验步骤（编号步骤①~⑤）
章2.2 结果分析（数据→趋势→归因→验证，五步循环）
章3 结论（科研结论+教学结论的双轨制）
```

**关键特征：**
- 摘要四句逻辑链：**平台搭建→结构组成→实验内容→培养效果**
- 引言"问题叠加型"论证：层层加压（产业需求→安全困境→现有平台不足）
- 结果分析"五步循环"：数据呈现→现象描述→机理归因→规律总结→文献验证
- 结论"双轨制"：先科研结论（核心发现），再教学结论（育人效果）

### 6.3 教学改革论文架构（OBE-CDIO范式）

**七段标准结构：**

```
引言（政策背景→人才需求→现存问题→本文方案→研究价值）
1 理论基础（OBE理念+CDIO理念的融合框架）
2 总体设计框架（理论→能力目标→项目设计→实施流程的逻辑图）
3 项目实施方案（阶段1→阶段2→阶段3递进）
4 评价体系（多维度评价指标+考核方式）
5 结语（总结+展望）
```

**关键特征：**
- 标题公式：`[理论框架]理念下[具体技术]的[教学类型]设计`
- 四图叙事：理论框架图→能力目标图→实施流程图→评价闭环图
- 结论用克制性措辞（"有助于""有助提升"）

### 6.4 英文学术论文架构（控制类）

**六段推进结构：**

```
1. Introduction（漏斗式：宽背景→具体问题→文献批判→本文贡献→论文结构）
2. System description（子系统分解：Stack / Blower / HX / Burner / Reformer）
3. Fault modeling（故障定义→数学模型→参数设置）
4. Simulation results（各工况仿真→对比分析→规律发现）
5. Discussion（综合讨论→机理阐释）
6. Conclusion（每条结论量化）
```

**关键特征：**
- 引言5段对应5个功能：背景/分类/批判/创新/路线图
- "否定式"引出贡献："there is no literature to..."出现5次
- 建模三步骤：系统分解→数学定义→模型连接

## 四、张涛论文架构（2026-06-01分析，6篇）

### 4.1 论文类型分布

| 类型 | 代表论文 | 架构模式 |
|------|---------|---------|
| 理论建模+数值仿真 | k/N系统维修策略分析、AOPN维修保障建模 | IMRaD变体，模型定义占40%+ |
| 方法研究+实验验证 | 考虑无线充电的无人机路径在线规划 | 引言→建模→方法→实验→结论，实验占比最大(~30%) |
| 综述+框架设计+案例 | 面向能源互联网的EMS研究 | 混合型：综述→框架提出→技术分析→案例验证 |
| 观点/问题-对策型 | 能源互联网在军事能源转型中的作用 | 背景→概念→问题→对策→结论 |
| 教改论文 | 军队工程硕士研究生培养 | 现状→问题→对策三段式 |

### 4.2 引言四种模式

| 模式 | 结构 | 代表论文 |
|------|------|---------|
| 漏斗式（从大到小） | 大背景→具体问题→文献综述→gap→贡献 | 无人机路径规划、面向能源互联网EMS |
| 递进式批评 | 一般方法(缺点)→改进A(不足)→改进B(仍有不足)→本文方案 | AOPN维修保障建模 |
| 问题驱动 | 宏大背景→问题聚焦→概念引出 | 能源互联网军事转型 |
| 直接切入 | 背景→问题→本研究 | 军队工程硕士研究生培养 |

### 4.3 实验对比四层递进（DRL论文标准范式）

```
第1层：方法内对比（贪心 vs 采样 vs 波束搜索）
第2层：同类型方法对比（DRL vs Pointer Network）
第3层：传统方法对比（DRL vs PSO/ACO/ALNS）
第4层：跨规模趋势（50→100→150→200节点）
```

### 4.4 五种结论模式

| 模式 | 结构 | 代表论文 |
|------|------|---------|
| 两段式（贡献+展望） | 1句贡献 + 1句优势 + 未来工作 | 无人机路径规划 |
| 两段式（贡献+未来） | 贡献总结+未来展望，不重复摘要 | 面向能源互联网EMS |
| 极简型 | 仅1句"做了什么+为什么重要" | AOPN、k/N系统 |
| "回环"收束式 | 历史回顾→趋势判断→定位重申→建议 | 能源互联网军事转型 |
| 三段式 | 回顾→总结→升华 | 军队工程硕士研究生培养 |
