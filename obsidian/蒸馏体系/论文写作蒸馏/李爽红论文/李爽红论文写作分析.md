## 2. 摘要写法

### 结构模式：五段式摘要
本论文英文摘要约 **400 词**，采用经典的**问题→框架→分点贡献**结构：

**段1 (背景+问题)**：「Industrial system will produce...」— 工业数据高维性 → 需要合适数据结构 → 提出张量标签学习策略

**段2 (统领性贡献)**：「This thesis studies the problems of...」— 统一表示异构信息数据，综合评估故障诊断系统

**段3-5 (分点贡献，Firstly/Secondly/Thirdly...Fifthly)**：
- Firstly: 建立张量标签学习框架（理论贡献）
- Secondly: 并发故障识别（向量标签学习）
- Thirdly: 迁移学习解决数据稀缺
- Forthly: 故障定位（特征选择+相似度度量）
- Fifthly: 容错控制（TS-BL-GPC）

### 摘要句式模板
```
> **T1** Industrial system will produce a lot of high-dimensional and high-order process data...
>     Based on the industrial process characteristics, ... are studied in this thesis by [方法名] strategy.
> *摘要 · 背景引出 + 方法声明 · 李爽红(2018)*

> **T2** The main contents of this thesis are as follows: Firstly, ... Secondly, ... Thirdly, ...
> *摘要 · 分点罗列贡献 · 李爽红(2018)*

> **T3** The experimental results show that the method can quickly obtain the model of [任务] using very few target domain data.
> *摘要 · 实验成效概括 · 李爽红(2018)*
```

### 摘要写作特点
- **正向评价性措辞**：无"better""superior"等比较级词汇，用陈述事实方式描述贡献（"are unified","is realized","are studied"）
- **被动语态为主**：全摘要几乎全部使用被动语态（"is proposed","is studied","is realized","is extended"），体现传统学术英语风格
- **信息密度高**：每个段落承载一个完整方法论点，不冗余
- **存在问题**：摘要存在较多语法错误和拼写错误（"tolorant","identificaiton","fortly","the the"重复），这是非母语写作的典型特征

## 3. 引言/绪论写法

### 结构模式：漏斗式
Ch1 采用典型的**宏观→微观→缺陷→本文方案**漏斗结构：

1. **1.1 研究背景** (p1-2)：工业故障诊断的重要性，引出"工业系统过程数据→故障诊断"主题
2. **1.2 文献综述** (p2-5)：分 `1.2.1 故障诊断方法` 和 `1.2.2 故障数据特征` 两大子部分，按方法类别分类
3. **1.3 研究现状**（张量相关）(p5-6)：`1.3.1 张量表示` + `1.3.2 01编码`，聚焦与本文直接相关的前沿
4. **1.4 容错控制** (p6-8)：`1.4.1 被动容错` + `1.4.2 主动容错` + `1.4.3`，交代控制系统背景
5. **1.5 存在的问题** (p8-10)：分5个子问题（故障检测、识别、定位、控制、评估）逐一指出不足
6. **1.6 本文工作与组织** (p10-13)：用图 1-4 组织结构图 + 对应章节说明

### 引言的句式特点
```
> **T4** [1-4] [5-8] [9-11] — 大量使用方括号引用，平均每段 ≥5 个引用，信息密度极高
> *引言 · 密集引用模式 · 李爽红(2018)*

> **T5** 分节标题采用"名词短语"格式：1.1 Background, 1.2 Literature Review, 1.3 Research Status...
> *引言 · 章节命名惯例 · 李爽红(2018)*
```

### 值得注意的问题
- **引用堆砌症**：多处出现 4-5 个引用连续排列（如 `[1-4]` `[5-8]`），缺乏对每篇文献的实质讨论
- **批判性不足**：文献综述以"有什么"为主，较少"缺什么"的批判性分析
- **过渡依赖图表**：图 1-4 承担了论文组织说明的核心功能

## 4. 研究方法/实验设计描述方式

### 方法层次结构
论文的方法论按**理论→算法→验证**三层递进组织：

**理论层**（Ch3）：从数学定义出发
- 先定义输入空间 $X \in \mathbb{R}^{n_s \times n_v}$，输出空间 $Y$
- 再定义性能度量 Pre、Rec、F1 的张量推广形式
- 最后给出 0阶→1阶→2阶→3阶标签学习的完整形式化

**算法层**（Ch4-7）：伪代码 + 解释文字
- 每个算法均有 Algorithm 编号（Algorithm 4.1, 5.1, 5.2, 6.1, 6.2, 6.3）
- Input/Output 明确标注
- 步骤编号清晰

**验证层**：表格对比 + 图示
- 大量使用 Table 做横向对比（如 Table 4-7, 7-5 等性能对比表）
- 每个实验结果都有对应 Fig 展示

### 实验描述的固定模式
```
> **T6** [实验名] is carried out on the SOFC system. The parameters are shown in Table [X].
>     The results (Fig [X]) demonstrate that [方法] achieves [X]% F1, compared to [baseline] at [Y]%.
> *方法 · 实验描述模板 · 李爽红(2018)*
```

### 方法章节的句法特征
```
> **T7** In order to solve the problem of [X], this chapter adopts [方法A] and [方法B]
>     to [目标]. Thus [效果] is realized.
> *方法 · 目的-手段-效果句 · 李爽红(2018)*
```

## 5. 结果分析与讨论的写作逻辑

### 实验结果的呈现逻辑
每个实验章节遵循：**实验设置(Table) → 数据展示(Fig) → 性能对比(Table) → 定性分析**

### 对比实验的"承认-反击"话术
```
> **T8** "The experimental results show that the method can quickly obtain the model of
>     simultaneous fault identification using very few target domain data."
> *结果 · 核心优势总结 · 李爽红(2018)*
```

### 表格设计特点
- **参数表** vs **结果表** 分离：`Table 4-6` 实验参数，`Table 4-7` 实验结果
- **多维度对比**：同时比较 F1、训练时间、测试时间（Table 5-5）
- **加粗最优值**：隐含通过数据分布展示优势

### 定性分析的层次
实验后的定性分析以"现象→原因→含义"三层推进：
1. 描述观察到的现象（如"故障 A 的 3D 距离从正常点 0.2"）
2. 解释物理原因（如"Pblower 和 NAir_control 与故障 A 最相关"）
3. 导出工程含义（如"可建立实时监测系统"）

## 6. 结论写法

### 结构模式：总结型结论（极简风格）
Ch8 (p153-154) 仅 **2 页**，非常简练，结构为：

1. **贡献总结** (p153)：逐一回顾论文完成的工作
2. **未来方向** (p154)：列出3个具体方向
   - (1) X → Tucker 分解
   - (2) CP → 更丰富张量结构
   - (3) GAN → 生成并发故障训练数据

### 结论句式
```
> **T9** This thesis studies the identification, location and fault-tolerant control problems
>     of industrial systems, and proposes the tensor label learning method.
> *结论 · 回顾性总结句 · 李爽红(2018)*

> **T10** In the future, [方向] can be used to [目标]. ... can replace ... for better performance.
> *结论 · 未来方向句 · 李爽红(2018)*
```

### 结论写作问题
- **过于简短**：2页结论对于150页论文显得单薄
- **缺少量化总结**：未回顾关键实验数据（如"F1达到94%"）
- **未来方向太抽象**：未给出具体的技术路线或初步想法
- **缺乏"结论力度"**：没有有力的收束句，论文在参考文献处戛然而止

## 7. 语言风格与句式特点

### 7.1 整体语言特征

**语态偏好**：**被动语态占绝对主导**，全文中主动语态（I/we）几乎不存在。这是典型的传统工程学科论文风格（2018年），但与当今"鼓励使用主动语态"的趋势有所偏离。

**时态使用**：
- 文献综述 → 一般现在时 ("studies show", "methods include")
- 方法描述 → 一般现在时 ("is proposed", "is defined as")
- 实验结果 → 一般现在时 ("Table X shows", "results demonstrate")

### 7.2 高频学术短语

#### 问题引出类
| 短语 | 中文对应 |
|------|----------|
| "In order to solve the problem of..." | 为了解决...问题 |
| "Aiming at the problem of..." | 针对...问题 |
| "Because of..." | 由于... |
| "...is difficult to identify" | ...难以识别 |

#### 方法提出类
| 短语 | 频率 |
|------|------|
| "...is proposed" | 极高 |
| "Based on..." | 极高 |
| "...is adopted" | 高 |
| "...is used to..." | 高 |
| "A new method based on..." | 中 |

#### 结果展示类
| 短语 | 用途 |
|------|------|
| "The experimental results show that..." | 引出实验结果 |
| "Compared with..." | 引出对比 |
| "It can be seen that..." | 定性观察 |
| "demonstrate the effectiveness" | 总结有效性 |

### 7.3 英文写作的主要问题

**语法/拼写错误（提醒：不要直接模仿）**：
- 摘要中有 "tolorant"（应为 tolerant）、"identificaiton"（应为 identification）
- "forthly" 应为 "Fourthly"
- 多处冠词缺失或误用 ("a lot of high-dimensional data" → "a large amount of")
- 重复词 ("the the")

**句式单调**：连续段落中大量使用 "is proposed / is studied / is adopted" 被动结构，缺乏句式变化

**连接词贫乏**：过度依赖 "and"，缺少 "moreover/furthermore/consequently/nevertheless" 等多样化连接词

### 7.4 值得提取的句式模板

```
> **T11** [方法名] is proposed to solve the problem of [问题描述].
>         Only [简单条件] can be used to predict [复杂情况].
> *句式 · 方法声明+核心洞察 · Ch4摘要段*

> **T12** The [系统名] includes two parts: [部分1] and [部分2].
>         The [域A] and [域B] of this study are different [属性],
>         and the [任务A] and [任务B] are the same.
> *句式 · 系统组成+对比 · Ch5摘要段*

> **T13** In order to solve the problem of [X] based on [Y],
>         the condition of [Z] based on [W] is proposed.
> *句式 · 问题→条件推导 · Ch6摘要段*
```

## 10. 值得学习的写作技巧

### 10.1 优点

1. **张量标签学习的命名策略**：提出全新概念并赋予明确数学定义，概念-记号-公式三位一体，可检索性强

2. **层次化性能度量**：将通用的 F1 分数从标量→向量→矩阵→张量逐级推广，每级都有明确的数学公式，理论完备性好

3. **"一章一应用"对应框架**：Ch4-7 分别对应 TLL 框架的不同阶数（1阶→迁移→2阶→0阶），体现了**框架指导应用**的论文组织逻辑

4. **实验配置参数集中展示**：Table 4-6 的实验参数一次性列出（PCA保留方差比99.1%、降维到10维、RBF核等），便于复现

5. **故障诊断树的定性补充**：在定量实验之外，使用 FITA（故障推理树）做定性分析（Fig 4-8），丰富了分析维度

### 10.2 不足之处

1. **摘要英文质量差距**：存在多处拼写和语法错误，不应被模仿
2. **Ch8 结论过于简略**：2页结论缺少对实验关键数据（94% F1等）的回顾
3. **句式单调**：全文被动语态 + "is proposed/is adopted" 重复过度
4. **引用堆砌**：多处用 `[1-4] [5-8]` 批量引用而非逐个讨论

### 10.3 可迁移的写作模式

**框架提出型论文的组织逻辑**：
```
Ch2 基础 → Ch3 框架（理论） → Ch4-7 逐步应用（从简单到复杂）
         ↘ Ch4: 最简单的应用（1阶识别）
         ↘ Ch5: 增加复杂度（迁移学习）
         ↘ Ch6: 增加维度（定位）
         ↘ Ch7: 最复杂应用（容错控制+实验验证）
→ Ch8 收束
```

**实验验证的"数据-方法-结果-分析"四段式**（每章内重复）：
```
实验设置(Table: 参数、数据量、评估标准)
  → 实验结果(Fig: 可视化 + Table: 定量对比)
  → 定性讨论(物理含义、工程启示)
  → 章节小结(一句话总结 + 引出下一章)
```
