## SOFC论文常用动词搭配

### 描述研究行为
- "X was proposed/developed/designed to..."
- "X was investigated/studied/analyzed"
- "X was compared/evaluated/assessed"
- "simulations/experiments were conducted/performed"

### 描述发现
- "the results show/indicate/demonstrate/reveal that..."
- "it was found/observed that..."
- "X exhibits/shows/displays..."

### 描述效果
- "X is improved/enhanced/increased/reduced"
- "X achieves/attains/reaches..."
- "X exhibits a significant/substantial improvement"

### 描述对比
- "compared with/to X..."
- "X outperforms/Y surpasses..."
- "X shows better performance than Y..."

## 论文写作"高频词替换"技巧

| 初级词 | 升级替换 |
|--------|---------|
| show | demonstrate, indicate, reveal, exhibit |
| use | employ, adopt, utilize, apply |
| improve | enhance, optimize, upgrade, ameliorate |
| big | significant, substantial, remarkable, considerable |
| good | excellent, superior, outstanding, favorable |
| new | novel, innovative, original, advanced |
| change | variation, alteration, modification, deviation |
| important | crucial, critical, essential, vital, significant |

## 写作建议

1. 每个主要动词在一篇论文中重复使用不超过3-4次，适当换词
2. 连接词不要只用"however"，交替使用"nevertheless/nonetheless/in contrast"
3. 技术名词保持一致性，不要为了换词而混淆术语
4. 描述词使用时要有数据支撑，不要空泛地"significant"
