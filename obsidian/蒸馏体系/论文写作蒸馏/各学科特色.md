# SOFC领域论文写作特色

> 基于吴肖龙博士论文 + Applied Energy SOFC论文蒸馏

## 一、SOFC论文常见要素

### 建模部分的必备内容
1. 电堆电化学方程（Nernst方程、欧姆极化、活化极化、浓差极化）
2. 能量守恒方程（各组件温度分布）
3. 质量守恒方程（气体组分变化）
4. 故障嵌入方式（衰变系数/泄漏系数等）
5. 建模假设的"清单式"前置

### 实验部分的必备内容
1. 系统架构图（含传感器位置）
2. BOP部件清单
3. 全工况实验方案
4. CFD模拟设置

---

## 二、博士论文 vs 期刊论文差异

| 维度 | 博士论文 | 期刊论文 |
|------|---------|---------|
| 篇幅 | 6章，完整体系 | ~15页，聚焦一个创新点 |
| 文献综述 | 全面覆盖，6+维度 | 精准聚焦，只引相关 |
| 方法描述 | 详细，公式推导完整 | 简洁，引用文献 |
| 图表 | ~75图23表 | ~14图4表 |
| 结论 | 总结+展望 | 3条量化bullet point |

---

## 三、SOFC论文的图表规范

### 必备图表类型
- 系统架构图/示意图
- 建模结果趋势图（参数随时间变化）
- 多方案对比图（四流场对比等）
- 数据表（参数设定表、节点分布表）
- 故障/模态分析表

### 制图规范
- 图名：统一"图X.Y 标题"
- 图-文配合："如图X.Y所示"引导
- 趋势图标注时间戳
- 多子图对比布局

## 三、SOFC/燃料电池领域论文写作特色（基于吴肖龙论文蒸馏）

### 3.1 SOFC论文常见写作套路

**摘要结构（中文）：**
```
四句法：定调→建模/实验方法→关键发现→价值意义
```
吴肖龙的教学论文摘要改用"平台搭建→结构组成→实验内容→育人价值"，但纯研究论文仍是经典四句法。

**引言三段式：**
1. 产业背景（市场规模+政策驱动+应用案例）
2. 技术难点（高温环境+监测困难+成本/安全因素）
3. 文献不足（针对某具体方向的研究空白）

**Modeling论文的标配元素：**
- 反应方程式（SOFC阴极/阳极/总反应，每个方程编号）
- 子模型列表（Stack / Reformer / Burner / HX / Blower）
- 参数表（包含名称、符号、值、单位四列）
- 假设条件（通常4-6条）
- 模型验证（仿真vs实验对比图）

### 3.2 中英双语论文写作规范（控制类）

| 维度 | 中文版 | 英文版 |
|------|--------|--------|
| 摘要 | 四句连贯 | 五句（多一句"差异性引出"） |
| 被动语态 | 低频使用 | 高频使用（is studied/has been developed） |
| 句子长度 | 30-50字长句 | 20-35词为主 |
| 图号引用 | "如图X所示" | "As shown in Fig. X" / "It can be seen from Fig. X" |
| 参考文献格式 | 中文期刊用中文 | 中文期刊英文名+中文名并列 |

### 3.3 常见"中国学者英文写作问题"（吴肖龙英文论文案例）

1. 拼写错误：关键词"failure anslysis"应为"analysis"
2. 冠词缺失或冗余："in this paper" vs "in the paper"混用
3. 单复数不一致："data"作为复数使用时谓语用单数
4. 介词搭配："compared with" vs "compared to"混用
5. 悬垂分词："Using the model, the results..." 主语不一致
6. 过于冗余表述："simulation and experimental research"可简化为"simulation and experiment"
7. 图号引用缺少前置介绍——直接引用而不是先文字描述趋势再引用图
8. 用词重复："studied"在文中出现8次，可用investigated/analyzed/examined替代

### 3.4 SOFC博士论文"四段递进"架构

```
第1层：认识系统（建模分析——理解SOFC运行机理）
  ↓
第2层：预测系统（性能预报——判断系统状态）
  ↓
第3层：诊断系统（故障检测——定位系统异常）
  ↓
第4层：控制修复（健康管控——维持系统健康）
```

每层对应博士论文的一章，形成从"认知"到"干预"的完整闭环。

## 二、国防科技大学系统工程学院多学科写作特色（2026-06-01分析，57篇）

基于张涛课题组及合作者57篇论文，覆盖5个方向，各方向的写作规范总结如下：

### 2.1 维修保障/可靠性方向（16篇）

| 维度 | 规范 |
|------|------|
| **问题来源** | 武器装备/军事背景，开篇有军事实例（"某型舰载雷达"） |
| **数学工具** | Markov过程、排队网络、Petri网、随机规划 |
| **验证方式** | 算例验证（设定假设参数做数值计算），不做实验 |
| **建模前奏** | "问题描述与假设"小节必不可少 |
| **结论** | 必含"下一步工作"段落 |
| **符号体系** | λ(故障率)、μ(修复率)、c(维修分队数)、Ao(使用可用度)跨论文一致 |

### 2.2 能源互联网/微电网方向（14篇）

| 维度 | 规范 |
|------|------|
| **方法论主线** | MPC框架（确定性MPC→SMPC→DMPC→鲁棒优化） |
| **核心隐喻** | 互联网分层思想（能源路由器、ELAN、分层递阶） |
| **标准工具** | 混合整数二次规划(MIQP) |
| **摘要** | 格式化"背景→方法→结果"三部曲 |
| **研究脉络** | 概念奠基(2012-2014)→架构构建(2015-2017)→深化(2019-2021) |

### 2.3 智能优化/多目标优化方向（9篇，含6篇综述）

| 维度 | 规范 |
|------|------|
| **综述结构** | 摘要(4段)→引言(3维分类)→主体→对比表→展望 |
| **分类法** | 三维分类框架（如"机制—模型—硬件"） |
| **必配元素** | 发展趋势统计图 + 算法对比表 |
| **展望写法** | 独立成节，每个点=局限性+方向+论证三段式 |
| **综述vs算法差异** | 综述:分类归纳+90篇引文 / 算法:方法创新+实验验证 |

### 2.4 锂电池/储能方向（8篇）

| 维度 | 规范 |
|------|------|
| **方法论** | 以数据驱动为主（GRU、LSTM、深度学习、PSO、聚类） |
| **验证** | 实验数据验证为主（与其他方向偏重算例不同） |
| **评价体系** | RMSE/MAE/MAPE三大误差指标 |
| **综述双线** | 物理原理线 + 方法演进线并行 |
| **对SOFC借鉴** | GRU→SOFC电压预测、Autoencoder→SOFC寿命预测、加速实验→SOFC加速老化 |

### 2.5 教改/教育管理方向（6篇）

| 维度 | 规范 |
|------|------|
| **结构** | 经典三段式（现状→问题→对策） |
| **摘要** | 多为单句式概述（所有方向中信息量最低） |
| **必引** | 中央军委/教育部政策文件 |
| **话语体系** | "扎实推进"、"积极推进"、"落到实处"等政策话语 |
| **案例复用** | "系统工程原理"课程出现于多篇论文 |

### 2.6 跨领域通用写作DNA

| 共性 | 说明 |
|------|------|
| **问题驱动** | 每篇都以实际需求切入 |
| **摘要四段式** | 背景→方法→求解→验证 |
| **引言漏斗式** | 大背景→问题→文献→gap→本文 |
| **枚举论证** | 偏好"首先/其次"、"①/②/③"编号 |
| **"本文"主语** | 中文论文几乎统一使用"本文"而非"我们" |

### 2.7 需要规避的常见问题

| 问题 | 表现 |
|------|------|
| 结论过弱 | 仅1-2句，无结果对比/局限/展望 |
| 摘要信息量不足 | 仅1句的教改论文摘要 |
| 缺乏定量验证 | 只有过程描述无具体数据 |
| 符号阅读体验差 | 密集符号嵌入段落 |
| 综述展望空洞 | "进一步研究"缺乏具体方向 |
| 引言综述堆砌 | "文献[1]...文献[2]..."流水账 |
