# SOFC领域论文写作特色

> 基于吴肖龙博士论文 + Applied Energy SOFC论文蒸馏

## 一、SOFC论文常见要素

### 建模部分的必备内容
1. 电堆电化学方程（Nernst方程、欧姆极化、活化极化、浓差极化）
2. 能量守恒方程（各组件温度分布）
3. 质量守恒方程（气体组分变化）
4. 故障嵌入方式（衰变系数/泄漏系数等）
5. 建模假设的"清单式"前置

### 实验部分的必备内容
1. 系统架构图（含传感器位置）
2. BOP部件清单
3. 全工况实验方案
4. CFD模拟设置

## 二、博士论文 vs 期刊论文差异

| 维度 | 博士论文 | 期刊论文 |
|------|---------|---------|
| 篇幅 | 6章，完整体系 | ~15页，聚焦一个创新点 |
| 文献综述 | 全面覆盖，6+维度 | 精准聚焦，只引相关 |
| 方法描述 | 详细，公式推导完整 | 简洁，引用文献 |
| 图表 | ~75图23表 | ~14图4表 |
| 结论 | 总结+展望 | 3条量化bullet point |

---

## 三、SOFC论文的图表规范

### 必备图表类型
- 系统架构图/示意图
- 建模结果趋势图（参数随时间变化）
- 多方案对比图（四流场对比等）
- 数据表（参数设定表、节点分布表）
- 故障/模态分析表

### 制图规范
- 图名：统一"图X.Y 标题"
- 图-文配合："如图X.Y所示"引导
- 趋势图标注时间戳
- 多子图对比布局

## 三、SOFC/燃料电池领域论文写作特色（基于吴肖龙论文蒸馏）

### 3.1 SOFC论文常见写作套路

**摘要结构（中文）：**
```
四句法：定调→建模/实验方法→关键发现→价值意义
```
吴肖龙的教学论文摘要改用"平台搭建→结构组成→实验内容→育人价值"，但纯研究论文仍是经典四句法。

**引言三段式：**
1. 产业背景（市场规模+政策驱动+应用案例）
2. 技术难点（高温环境+监测困难+成本/安全因素）
3. 文献不足（针对某具体方向的研究空白）

**Modeling论文的标配元素：**
- 反应方程式（SOFC阴极/阳极/总反应，每个方程编号）
- 子模型列表（Stack / Reformer / Burner / HX / Blower）
- 参数表（包含名称、符号、值、单位四列）
- 假设条件（通常4-6条）
- 模型验证（仿真vs实验对比图）

### 3.2 中英双语论文写作规范（控制类）

| 维度 | 中文版 | 英文版 |
|------|--------|--------|
| 摘要 | 四句连贯 | 五句（多一句"差异性引出"） |
| 被动语态 | 低频使用 | 高频使用（is studied/has been developed） |
| 句子长度 | 30-50字长句 | 20-35词为主 |
| 图号引用 | "如图X所示" | "As shown in Fig. X" / "It can be seen from Fig. X" |
| 参考文献格式 | 中文期刊用中文 | 中文期刊英文名+中文名并列 |

### 3.3 常见"中国学者英文写作问题"（吴肖龙英文论文案例）

1. 拼写错误：关键词"failure anslysis"应为"analysis"
2. 冠词缺失或冗余："in this paper" vs "in the paper"混用
3. 单复数不一致："data"作为复数使用时谓语用单数
4. 介词搭配："compared with" vs "compared to"混用
5. 悬垂分词："Using the model, the results..." 主语不一致
6. 过于冗余表述："simulation and experimental research"可简化为"simulation and experiment"
7. 图号引用缺少前置介绍——直接引用而不是先文字描述趋势再引用图
8. 用词重复："studied"在文中出现8次，可用investigated/analyzed/examined替代

### 3.4 SOFC博士论文"四段递进"架构

```
第1层：认识系统（建模分析——理解SOFC运行机理）
  ↓
第2层：预测系统（性能预报——判断系统状态）
  ↓
第3层：诊断系统（故障检测——定位系统异常）
  ↓
第4层：控制修复（健康管控——维持系统健康）
```

每层对应博士论文的一章，形成从"认知"到"干预"的完整闭环。

## 四、控制科学与工程/机器学习故障诊断领域写作特色（2026-07-01蒸馏）

基于李爽红博士论文（SJTU, 2018）蒸馏。

### 4.1 "提出理论框架型"博士论文的写作规范

**领域定位**：控制科学与工程 — 工业故障诊断，方法论驱动型研究

**论文类型**：理论框架提出 + 多应用验证（英文博士论文，179页）

### 4.2 张量/机器学习类论文的标志性特征

1. **符号密集型**：全文大量使用张量符号（$\mathcal{X}$, $\mathcal{Y}$, $\|A\|_F$, $\circ$, $\otimes$），符号定义集中在 Ch2，后续章只引用不重定义

2. **数学形式化先行**：每个方法/概念必须先给出严格的数学定义（输入空间→输出空间→决策函数→性能度量），再做算法描述

3. **性能度量的统一推广**：将标量指标（F1-score）推广到张量形式（F1_0, F1_1, F1_2, F1_3），这是该领域的典型手法——用数学统一性论证方法普适性

4. **算法伪代码标准化**：每个算法使用 `Algorithm X.Y` 编号，Input/Output 明确标注，步骤编号清晰

### 4.3 SOFC应用领域写作特色

**SOFC系统描述的固定套路**：
```
(1) 系统结构总览（Fig + BOP组件列表）
(2) 电堆电化学特性（U-I-P曲线，温度工况）
(3) 关键变量列表（197变量 → PCA降维 → 10主成分）
(4) 故障类型定义表（泄漏系数λ = 0.8，10类故障）
```

**SOFC论文的表格式结果对比**（Table 5-5 模式）：
- 同时展示：F1（单故障/并发故障/平均）+ 数据量 + 训练/测试时间
- 最优值加粗或不加粗，让数据自己说话
- 横跨多个对比维度（SL vs ML, SVM vs RF, with/without Transfer Learning）

### 4.4 中英双语特征的独特表现

这篇论文的 text 提取显示，**中文部分（内容简介/目录/参考文献）的字符被 pdftotext 正确提取但存在排版碎化**，这反映了 2018 年国内高校博士论文的一个特征：中英文混排、数学公式密集、LaTeX 排版。

| 特征 | 表现 |
|------|------|
| 正文语言 | 英文为主 |
| 章节标题 | 中英混用（目录同时有中英文标题） |
| 参考文献 | 中英混合（~70%英文, ~30%中文期刊） |
| 公式排版 | LaTeX 风格编号 `(2.1)` `(3.24)` |
| 图表标注 | 双语图注 "Fig X-Y en_title / 图 X-Y zh_title" |

### 4.5 该领域的写作共性DNA（与张涛、吴肖龙对比）

| 共性 | 李爽红(SJTU) | 张涛(NUDT) | 吴肖龙 |
|------|-------------|-----------|--------|
| 问题驱动开篇 | ✅ "Industrial system will produce..." | ✅ 军事/工程实例切入 | ✅ 能源产业背景切入 |
| 漏斗式绪论 | ✅ 工业→SOFC→张量→本文 | ✅ 产业→学术→gap→本文 | ✅ 产业→技术难点→文献不足 |
| 表格密集型实验 | ✅ Table 4-7, 5-5, 7-9 等 | ✅ 算法对比表 | ✅ 参数设定表、节点分布表 |
| 章末小结 | ✅ 每章末有短小结 | ✅ 结论段 | ✅ 每章"本章小结" |
| 被动语态（英文） | **极高**（>95%） | 中等 | 中等 |

**核心差异**：李爽红论文的**方法论色彩最重**——Ch3 不解决任何具体应用问题，纯粹做理论框架的形式化，这在三篇论文中是独有的。张涛和吴肖龙的论文都以具体应用问题驱动。这使得李爽红的论文更适合作为 **"框架提出型论文"** 的写作范本。
