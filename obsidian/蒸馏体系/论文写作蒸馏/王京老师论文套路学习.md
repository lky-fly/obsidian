> 作者：张海涛，王京（兰州大学信息学院）
> 类型：学术期刊论文（14页）

---

## 一、整体架构

```
摘要（~350字）
├── 背景1句 -> 问题1句 -> 已有方法1句 -> 本文方案2句 -> 实验1句 -> 结果1句
│
1. 引言（~3页）
├── 1.1 背景+问题引出（3段：背景->黑盒问题->解释性方法的必要性）
├── 1.2 文献综述（现有方法分类：两类方法分别评述）
├── 1.3 本文方案（针对XX问题，基于XX技术，提出XX方法）
├── 1.4 实验设计（模型选择+数据集+对比方法）
├── 1.5 结果总结（一句话结论）
└── 1.6 创新点（两点创新，用"第一""第二"列出）

2. 相关工作（~2页）
└── 按方法分类综述（样本生成/样本遍历/单样本/多样本）

3. 方法描述（~4页）
├── 3.1 输入图像与实际执行
├── 3.2 符号化图像
└── 3.3 像素分类贡献值

4. 实验与分析（~3页）
5. 结论（~0.5页）
```

## 三、引言写法分析（核心套路）

### 引言的三段式结构

**第一段：背景铺垫（从宏观到具体）**
```
"随着XXX的持续提升，XXX经过XXX改进，作为XXX，已经被广泛应用于XXX，如XXX。"
```
先交代大背景，再聚焦到具体技术领域，列举典型应用。

**第二段：平稳叙述技术流程**
```
"如果XXX确定后，紧接着XXX，经过XXX之后即可应用于XXX。"
```
用一段客观描述技术的基本流程，为后面的转折做铺垫。

**第三段：抛出核心问题（关键词："然而"）**
```
"然而，训练获得的XXX往往是一个XXX。虽然XXX已知，但XXX难以被感知和理解，因此XXX也被称为XXX。"
```
这是全文最重要的转折段。套路：
- "虽然XXX已知"（先肯定已知部分）
- "但XXX难以被感知和理解"（指出核心问题）
- "因此XXX被称为XXX"（给问题贴上标签）

**第四段：深化问题的影响**
```
"由于XXX的黑盒属性，虽然XXX符合预期，但是XXX非常困难，因此XXX目前被公认为是不可信的。"
```
把技术问题的严重性放大到"不可信"的程度。

**第五段：提出了解决方向**
```
"为了提高XXX的可信度，一种常见的方法是XXX，其核心思想为：XXX。"
```
温和地引出现有解决思路，描述其核心思想。

**第六段：现有方法分类评述**
```
"根据XXX不同，现有方法可被划分为两类：A方法和B方法。A方法的核心思想为：XXX。B方法的核心思想为：XXX。"
```
对现有方法进行分类，每类简要说明核心思想。

**第七段：现有方法的不足 + 本文方案（关键词："但" + "据我们所知"）**
```
"但此类方法由于XXX，往往需要一个巧妙的构思并且基于大量的推理证明才能设计一个具有较高准确度的解释性方法。据我们所知，目前还没有一种方法能够XXX。"
```
先用"但"转折指出A类方法的不足，再用"据我们所知"强调B类方法也还不完美。

**第八段：本文方案详细说明**
```
"本研究针对现有XXX不足的问题，基于XXX技术，依赖XXX，提出一种新颖的XXX方法。本研究提出的方法的核心思想为：XXX。"
```
这是引言的核心段。套路：
1. "针对XXX不足的问题"（呼应前述不足）
2. "基于XXX技术"（给出技术路线）
3. "提出一种新颖的XXX方法"（给出方法名称）
4. "核心思想为：XXX"（一句话说清原理）

**第九段：实验设计**
```
"基于XXX，本研究开展了大量的实验对提出的方法进行了系统地评估。XXX被选作为XXX，XXX被采用作为XXX，并且XXX被选取作为对比方法。"
```

**第十段：一句话结果 + 两点创新**
```
"测评实验结果表明：XXX。总体而言，相对于现有方法，本研究提出的方法创新有二：第一，XXX；第二，XXX。"
```

## 四、文献综述（相关工作）写法

### 分类综述法（不是时间线综述）

```
第一类：A方法
  - 代表方法1：核心思想为XXX
  - 代表方法2：核心思想为XXX

第二类：B方法
  - 代表方法1：核心思想为XXX
  - 代表方法2：核心思想为XXX
```

### 每类综述的句式模板
```
"XXX方法的核心思想为：首先XXX；紧接着XXX；然后XXX；最终XXX。"
"XXX方法使用XXX策略，基于XXX完成XXX。"
"XXX作为最具代表性的方法，得益于XXX已被广泛关注。"
```

### 综述末尾的承接句
```
"总体而言，A方法具有XXX优势，然而A方法目前还没有一种方法能够XXX。基于A策略，本研究提出的方法使用XXX技术，与现有方法使用的计算原理都不相同，并且是一种具有XXX的方法。"
```

## 五、方法描述写法

### 标准句式
```
"本研究依赖XXX，基于XXX技术，提出的具有XXX能力的XXX方法的计算流程如图X所示。"
```

### 步骤描述模板
```
"第一步，首先以XXX作为输入驱动XXX进行XXX，同时获取并记录XXX。"
"第二步，定义一个XXX作为输入，并以记录的XXX作为指导，对XXX进行XXX。"
"第三步，基于XXX的结果，假设XXX作为目标，得到一个XXX。"
"第四步，在XXX中提取XXX，并构建一个XXX。"
"第五步，首先对XXX进行XXX计算，然后对XXX进行XXX处理，最终输出XXX。"
```

### 关键句型
```
"对于我们而言，最为关心的问题是：为什么XXX被XXX分类为一个特定类别，也即XXX被分类某一类别的依据是什么。"
```
用一个设问句引出方法要解决的问题。

## 八、语言风格特点

### 高频句式结构
1. "作为XXX"（开篇定调）："作为一种卓越的具有自学习特征的网络结构"
2. "然而..."（转折）：全文出现5+次，每个关键论点必用
3. "据我们所知..."（强调新颖性）："目前还没有一种方法能够..."
4. "针对XXX不足的问题"（引出方案）
5. "总体而言"（总结段意）
6. "例如"（举例说明）
7. "核心思想为："（方法描述）
8. "目前被公认为..."（建立共识）

### 句式长度特点
- 长句为主（30-80字），信息密度高
- 每段平均4-6句
- 段末必有小结句

### 衔接词使用
| 衔接词 | 作用 | 频次 |
|--------|------|------|
| 然而 | 转折引问题 | 高 |
| 因此 | 引出结论 | 高 |
| 总体而言 | 段末总结 | 中 |
| 据我们所知 | 引出创新 | 1次（关键位置） |
| 例如 | 举例说明 | 中 |
| 首先/紧接着/然后/最终 | 流程描述 | 高 |

## 十、最值得学习的3个写作技巧

### 技巧1：引言的三段式破题法

王京老师论文的引言组织非常清晰：
```
第一段：大背景（"随着XXX"）
第二段：平稳叙述技术流程（"如果XXX"）
第三段：抛出核心问题（"然而"）
第四段：放大后果（"目前被公认为不可信"）
第五段：提出解决方向（"一种有效方法是XXX"）
第六段：分类综述（"根据XXX不同，可划分为两类"）
第七段：指出不足（"但/据我们所知"）
第八段：本文方案（"本文针对XXX不足，提出XXX"）
第九段：实验设计
第十段：结果+创新点
```

**核心就是："然而"放在第三段，不早不晚；先用两段铺垫，再抛出问题。**

### 技巧2：创新点的"第一....第二..."排比式表达

在引言末尾用"总体而言，本研究提出的方法创新有二：第一...第二..."的句式，简洁有力。前半句综述不足，后半句说明本文如何解决。这种结构在中文期刊论文中非常标准且有效。

### 技巧3：设问句引出方法论

```
"对于我们而言，最为关心的问题是：为什么一个输入图像X被目标网络模型f(X)分类为一个特定类别？"
```
在方法部分开头用一个设问句，直接告诉读者本部分要解决什么问题。这种"先问再答"的方式比平铺直叙更有吸引力。
