## 三、各论文架构分析

### 3.1 教学实验平台建设论文（中文）

**六段标准结构：**

```
摘要（四句）→ 引言（四段）→ 实验装置描述 → 实验步骤 → 结果分析 → 结论（双轨制）
```

**摘要四句逻辑链：**
```
第1句（定性+对象）：搭建了[平台]。
第2句（构成+功能）：该平台由[子系统A、B、C]组成。
第3句（研究内容+结果）：通过模拟[过程]，研究[因素]对[指标]的影响。
第4句（育人价值）：实验鼓励……增强……培养了[能力/精神]。
```

**引言"问题叠加型"论证（四段）：**
```
第1层（背景）：SOFC技术的产业化突破与市场化需求
第2层（问题）：用"然而"转折，指出成本高、消耗大、安全隐患
第3层（已有方案不足）：现有平台的三个缺陷：
  - 难以模拟复杂环境下的多运行工况
  - 实验可操作性差且匹配度低
  - 无法满足教学和创新人才培养要求
第4层（引出研究）：「因此，亟须建设[平台]。」——一句话收束
```

**结果分析"五步循环"：**
```
数据呈现 → 现象描述 → 机理归因 → 规律总结 → 文献验证
```
每个实验数据呈现后紧跟化学反应机理解释（如写入阴/阳极反应方程式），最后用"与文献相同[编号]"验证。

**结论"双轨制"：**
- 第1段：**科研结论**（总括→平台价值→核心发现→用了字收束）
- 第2段：**教学结论**（科研成果转化→育人效果）

### 3.2 博士论文（179页）

**"四段递进"架构：**

```
第1层　认识系统——第2章 SOFC系统多模态建模分析（机理建模）
第2层　预测系统——第3章 温度安全分析与性能预报（状态预测）
第3层　诊断系统——第4章 故障检测与实证分析（故障诊断）
第4层　控制修复——第5章 热电抖振的健康管控方法（控制修复）
```
形成从"认知"到"干预"的完整闭环。

**摘要结构（约500字，5段）：**
```
首段：宏观背景→研究对象→核心方法（约120字）
四段主体：按"首先/其次/然后/最后"逐一概述各章核心工作
末段：总结技术路线，提炼价值（"以机理模型为基础、数据驱动为补充"）
```

**绪论组织（三层漏斗）：**
```
1.1 研究背景：大背景（全球能源危机）→中背景（氢能战略）→小背景（SOFC技术）
1.2 研究意义：系统组成→高温困难→核心问题
1.3 文献综述：国外产业→国内产业→学术研究（建模/实验/预测/诊断/管控）
```

**各章统一结构：** 每章包含「引言 → 理论/方法 → 实验/仿真 → 结果分析 → 本章小结」

**博士论文加分项：**
- 技术路线图（图1.5）——可视化呈现研究框架
- 主要符号表（6页，从A到希腊字母）
- 附录1：已发表论文及授权专利目录
- 附录2：公开发表的学术论文与博士学位论文的关系

### 3.3 英文期刊论文（故障仿真对比）

**六段推进结构：**

```
1. Introduction（漏斗式5段：背景/分类/批判/创新/路线图）
2. System description（子系统分解：Stack / Blower / HX / Burner / Reformer）
3. Fault modeling（故障定义→数学模型→参数设置）
4. Simulation results（各工况仿真→对比分析→规律发现）
5. Discussion（综合讨论→机理阐释）
6. Conclusion（每条结论量化）
```

**引言5段的功能对应：**
| 段落 | 功能 | 标志词 |
|------|------|--------|
| §1 | SOFC优势背景 | due to its advantages |
| §2 | 故障诊断分类 | However, there are still challenges |
| §3 | 文献三个批判点 | there is no literature to... (×5) |
| §4 | 四条件创新点 | To address this issue, this paper... |
| §5 | 论文路线图 | The remainder of this paper is organized... |

**建模三步骤：**
```
① 系统分解（将SOFC拆解为5个子系统）
② 数学定义（每个子系统用方程建模）
③ 模型连接（子系统间通过物理量连接）
```

### 3.4 教学改革论文（OBE-CDIO）

**七段标准结构：**

```
引言（政策背景→人才需求→现存问题→本文方案→研究价值）
1 理论基础（OBE理念+CDIO理念的融合框架）

3 项目实施方案（阶段1→阶段2→阶段3递进）
4 评价体系（多维度评价指标+考核方式）
5 结语（总结+展望）
```

**标题公式：**
```
[理论框架]理念下[具体技术]的[教学类型]设计
示例：OBE-CDIO理念下可逆固体氧化物电池智能管控实训项目教学设计
```

**四图叙事链：**
```
图1 理论框架图 → 图2 能力目标图 → 图3 实施流程图 → 图4 评价闭环图
```

**结论措辞特色：** 克制性用语（"有助于""有助提升"），避免夸大效果。

## 四、句式与用词

### 4.1 中文常用句式模板

**背景引入：**
```
[技术]是通过……从而实现……的设备，该类技术在[应用领域]得到推广应用，取得了[成果]。
然而，随着[条件]的不断提升，[问题]为[对象]带来了不利因素。
```

**问题批判：**
```
难以[动词]……，实验[可操作性]差且匹配度低，无法满足[要求]。
[对象]占地面积大，操作复杂，[特性]差，环境适应性差，应用程度化低。
```

**引出必要性：**
```
因此，亟须[行动/建设/提出][对象]。
```

**结构说明：**
```
[系统]由[子系统A]、[子系统B]、[子系统C]及[子系统D]组成。
[子系统]用于控制[对象]的[参数]，[监测]的实现依靠[传感器]。
```

**数据描述+归因：**
```
由图X可见，[A]随[B]的升高[趋势]，说明[C]导致了[D]。
当[A]固定不变时，无论是[B]如何变化，[C]变化很小，这说明[D]。
这是因为[机理解释]，由于[原因]，[结果]是正常现象。
```

**规律总结：**
```
[因素1]对……具有积极作用，[因素2]是……的主控因素。
利用本装置测得……规律与文献相同，说明了本[装置]的适用性和准确性。
```

**结论收束：**
```
设计了[系统]，实现了[功能]。——了字收束
为探究……提供了[资源]，丰富了[手段]。
研究结果对于……具有指导意义。
这是典型的科研成果转化为创新性实验教学资源。
对培养学生的……，提高学生的……发挥了积极作用。
```

## 五、语言风格特点

### 5.1 中文写作特征

- **客观性优先**：大量使用被动式（被吹出、被激活、被催化裂解）
- **术语标准化**：首次出现写全称，后续用缩写（固体氧化物燃料电池→SOFC）
- **衔接词丰富**：然而、同时、此外、可见、说明、这是因为
- **数字精确控制**：每个参数都有具体数字，无虚指数量词
- **长句占比较高**：常出现30-50字长句，含多层定语和状语
- **控制变量法论证**：实验中固定一个变量变另一个，分析逻辑清晰

### 5.2 英文写作特征

- **被动语态高频**：is studied / has been developed / are made
- **现在时为主**（摘要引言）→ 过去时（方法结果）
- **图号引用固定句式**：It can be seen from Fig.X...（出现6次）
- **因果解释固定句式**：The reason is that...（出现4次）
- **第一人称使用节制**：仅用"this paper"不用"we"

### 5.3 需要注意的英文问题（吴肖龙论文案例）

1. 拼写错误：关键词"failure anslysis"→analysis
2. 冠词混用：in this paper vs in the paper
3. 单复数不一致：data作为复数时谓语用单数
4. 介词搭配混用：compared with vs compared to
5. 悬垂分词：Using the model, the results...（主语不一致）
6. 用词重复：studied在一篇文中出现8次→可替换为investigated/analyzed/examined

## 六、SOFC领域论文写作规范

### 6.1 摘要写法

| 论文类型 | 摘要结构 | 示例 |
|---------|---------|------|
| 教学实验类 | 平台搭建→结构组成→实验内容→育人效果 | 四句法 |
| 博士论文 | 宏观背景→各章概述(首先/其次/最后)→技术路线提炼 | 五段法 |
| 英文期刊 | 背景→差异性引出→本文工作→方法验证→结果意义 | 五句法 |
| 教学改革类 | 背景→方法→内容→结果 | 四段法 |

### 6.2 SOFC论文标配元素

- **反应方程式**：SOFC阴极/阳极/总反应（每个方程编号）
- **子模型列表**：Stack / Reformer / Burner / HX / Blower
- **参数表**：名称、符号、值、单位四列
- **假设条件**：通常4-6条
- **模型验证**：仿真vs实验对比图
- **极化曲线**：电化学极化区→欧姆极化区→浓度极化区

### 6.3 中英双语论文规范（控制类）

| 维度 | 中文版 | 英文版 |
|------|--------|--------|
| 摘要 | 四句连贯 | 五句（多一句差异性引出） |
| 被动语态 | 低频使用 | 高频使用 |
| 句子长度 | 30-50字长句 | 20-35词为主 |
| 图号引用 | 如图X所示 | As shown in Fig.X / It can be seen from Fig.X |
| 参考文献 | 中文期刊用中文 | 中文期刊英文名+中文名并列 |
