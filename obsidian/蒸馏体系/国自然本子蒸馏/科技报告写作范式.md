# 科技报告写作范式

> 基于20份国家重点研发计划科技报告蒸馏

## 一、科技报告的标准结构

```
封面（项目编号+密级+标题）
编写说明（编写单位+编写人员+时间）
基本信息表
目录
插图清单
附表清单
正文（各章）
  第1章 引言/背景
  第2章 研究进展
  第3章 关键技术
  ...
  最后一章 小结
总结及展望
参考文献
```

## 二、正文五段式写作模板

每章采用：
```
背景综述 -> 存在问题 -> 技术方案 -> 实验验证 -> 小结
```

### 标准句式模板
```
"本章针对XXX问题，提出了XXX方法/技术"
"首先分析了XXX，然后设计了XXX，最后验证了XXX"
"实验结果表明，XXX具有XXX优势"
"综上所述，XXX能够有效解决XXX问题"
```

## 三、数据呈现方式

1. 数学公式（(X-Y)编号）
2. 性能对比表格
3. 仿真/实验曲线图
4. 系统架构图
5. 统计指标数据表
6. 项目基本信息表
7. 文献引用标注
8. 示范工程数据

## 四、科技报告 vs 年度报告差异

| 维度 | 科技报告 | 年度报告 |
|------|---------|---------|
| 侧重 | 技术深度+可复现性 | 管理执行+目标考核 |
| 模板 | 固定（科技部制） | 偏行政报告风格 |
| 内容 | 技术方案+实验验证 | 进展情况+经费执行 |
| 读者 | 技术专家 | 项目管理方 |

## 五、高质量科技报告撰写要点

1. 严格按照科技部模板格式
2. 每个技术点都有理论+实验支撑
3. 数据呈现多样化（公式+表+图）
4. 每章末尾有"小结"提炼
5. 下一章开头与上一章小结呼应
6. 关键技术问题要有标准表述
7. 技术方案和验证结果一一对应
