## 二、八大共性写作套路

### 套路1：立项依据"三部曲"
```
政策背景 -> 行业痛点 -> 凝练需求（"亟需..."句式结尾）
```
每段使用"然而->因此->亟需"作为标准转折链条。

### 套路2：文献综述"二分法"
先国外后国内，每个方向用"但是"转折引出不足。
引用方式：国际标杆 -> 国内代表 -> 不足提炼

### 套路3：摘要"六段式"标准结构
```
研究背景 -> 关键问题 -> 总体目标 -> 课题设置 -> 创新亮点 -> 预期成果
```
高度模板化，每份本子都遵循这个结构。

### 套路4：研究内容"倒三角"组织
```
1个核心科学问题 -> 3-4个关键技术 -> 4-5个课题/任务
```
课题间标注"输出-使用"关系，形成技术闭环。

### 套路5：创新点"三位一体"公式
```
提出（新概念/新方法）-> 突破（关键技术）-> 实现（性能超越）
```
三层次：国际对标（填补空白）-> 理念创新（新概念）-> 指标超越

### 套路6：课题设置的价值链/层级解耦逻辑
课题1->2->3->4->5 呈线性递进关系：
```
机理分析 — 关键材料 — 性能调控 — 系统集成 — 实证应用
```

### 套路7："对标+超越"叙事框架
承认跟跑国际先进水平，但说明如何突破。
"针对XXX（问题），提出XXX（方法/技术）"

### 套路8：语言符号化
高频句式模板高度一致：
- "亟需突破XXX"
- "揭示XXX机理"
- "构建XXX方法/体系"
- "形成XXX能力"

## 三、六种本子类型及其写作特点

### 1. 重大专项（3500万+）
特点：指南响应度高、工程验证闭环、产业协同完整
代表性本子：3500（4550万）、3700（4280万）

### 2. 揭榜挂帅/卡脖子
特点：突出"卡脖子"瓶颈、国产替代、工程出口明确
代表性本子：2100

### 3. 青年科学家
特点：突出学术锐气、原创概念、顶刊成果基础
代表性本子：5600（动态韧性域）、3300（国际工作组）

### 4. 仿真/软件类
特点：以软件/平台为核心成果、生态建设模式
代表性本子：1700

### 5. 产品/装备类
特点：国际首台套、技术路线并行、世界性挑战
代表性本子：3700

### 6. 验证/示范类
特点：精准示范、赛马制、替代验证
代表性本子：3400

## 四、高频句式与模板

### 立项依据标准句式
```
"随着XXX的发展，XXX面临严峻挑战"
"然而，现有XXX存在XXX问题"
"因此，亟需开展XXX研究"
```

### 研究内容标准句式
```
"针对XXX（问题），提出XXX（方法），突破XXX（技术），形成XXX（能力）"
"研究内容一：XXX机理研究"
"研究内容二：XXX关键技术"
```

### 创新点标准句式
```
"提出了一种全新的XXX方法"
"突破了XXX的技术瓶颈"
"实现了XXX性能的显著提升"
```

### 考核指标标准句式
```
"形成XXX技术/系统/平台"
"申请发明专利X项"
"发表SCI论文X篇"
"培养博士/硕士研究生X名"
```

## 五、与国自然青基的核心差异

| 维度 | 国自然青基 | 国家重点研发计划 |
|------|-----------|----------------|
| 导向 | 科学问题驱动 | 指南响应驱动 |
| 核心 | 原创理论/学术贡献 | 技术突破/工程应用 |
| 团队 | 个人+1-2人 | 大团队（5+课题，多单位） |
| 经费 | 30万 | 500-5000万 |
| 周期 | 3年 | 3-5年 |
| 篇幅 | ~8000字 | 数万字（含各课题详细方案） |
| 创新点 | 3个科学创新 | 技术突破+工程创新 |
| 成果 | 论文为主 | 系统/平台/专利/标准为主 |
| 可行性 | 理论可行+基础 | 实验条件+团队+已有基础 |
