# 国自然本子整体写作架构

## 标准架构

（一）立项依据（约40%篇幅）
- 1.1 研究意义（三层次递进：政策 -> 工程 -> 本子核心）
- 1.2 国内外现状（三级标题分方向综述，每段末批评）
- 1.3 亟待解决的问题（提炼3个，对应后文内容+创新）

（二）研究内容、目标、关键科学问题（约20%）
- 研究目标（框架 -> 算法 -> 平台）
- 研究内容（3+1模式）
- 关键科学问题（2个）

（三）研究方案及可行性分析（约25%）
（四）特色与创新（约8%）
（五）年度计划与预期成果（约7%）

## 核心写作原则
1. 每个段落末尾都要"点题"
2. "然而"要用得精准
3. 创新点不超过3个
4. 关键科学问题提炼2个最佳
5. 预期成果量化
6. 前期基础要"强相关"
7. 参考文献要高档次+新+自己
8. 语言学术化但不晦涩
