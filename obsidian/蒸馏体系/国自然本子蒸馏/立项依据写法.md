# 立项依据写法总结

> 基于郭志军（南昌大学）2023青基 + 2024省基两份已中标申请书蒸馏

## 一、总体架构：三段式递推

[政策/战略背书] -> [工程痛点] -> [两个核心矛盾] -> "因此本项目具有重要研究意义"
    -> [分方向综述（每段=历史+现状+不足）]
    -> [1.3 亟待解决的问题（提炼3个大问题）]

### 关键节奏
- 立项依据占全文约40%篇幅（青基最重头）
- 每个段落末尾都要点题
- 转折词（"然而""但""值得注意的是"）精准使用

---

## 二、研究意义写作模板

### 三层递进

第一层：国家战略/政策文件背书（开篇定调）
"国务院在2017年发布的《XXX》中指出...因此，XXX是研究前沿/国家重大战略需求"
套路：引用国家文件/院士观点 -> 定位到"国家需求"

第二层：工程应用痛点（从宏观到具体）
"大量工程实践可建模为XXX问题，例如XXX。然而传统方法受限于XXX...迫切需要XXX"
套路：举1-2个具体应用 -> 对比集中式vs分布式优点 -> 强调必要性

第三层：聚焦本项目的核心矛盾（2条主线）
每条线用"若不...就..."紧迫句式

### 每段收束句模板
"综上所述，本项目拟研究XXX。因此，本项目具有重要研究意义。"

---

## 三、国内外研究现状写作模板

### 每个子方向的"三段式"模板

Step 1 - 类史梳理
"XXXX年，XXX教授首先提出XXX[ref]"
"借鉴于XXX技术，研究人员提出了XXX"

Step 2 - 段末批评（关键！）
"值得注意的是，现有工作尚存在以下不足：1) XXX 2) XXX"
或 "然而，上述算法均只能实现XXX，无法XXX"

Step 3 - 过渡句
"因此，迫切需要研究XXX"

### 参考文献策略
- 经典文献（领域奠基之作）+ 最新文献（当年发表）
- 高档次期刊为主：IEEE Trans. / Automatica / 中国科学
- 适当引用中文文献（5-8篇）
- 巧妙引用自己论文（展示研究延续性）
- 自然融入叙述，而非"[1]-[3]"堆砌

---

## 四、"亟待解决的问题"提炼模板

从文献综述提炼3个问题，每个用"现有...尚不..."句式：
三个问题正好对应后续"研究内容"的三个方面，也对应"创新点"三个方面
形成"问题 -> 内容 -> 创新"的完整闭环

---

## 五、省基特有的要求
1. 必须提及对地方的带动作用（如"助力江西省'1269行动计划'"）
2. 周期短、经费少：省基2年/10万 vs 青基3年/30万
3. 模板更灵活，申报学科可填2个
4. 有绩效目标量化表
5. 团队可以带学生

---

## 六、语言风格要点

| 功能   | 常用表达                 |
| ---- | -------------------- |
| 定调   | 毫无疑问、研究前沿、国家重大战略需求   |
| 转折   | 然而、但、值得注意的是、尚存在      |
| 引出方案 | 鉴于此、有鉴于此、因此、为此       |
| 评价   | 结构简单、通用性强、易于实施、收敛速度快 |
| 收束   | 综上所述、由此可见、因此         |
