# 重点研发计划项目管理与评审标准

> 基于13份任务书 + 5份中期报告/专家意见蒸馏

## 一、专家评审维度（中期检查）

| 维度 | 权重（估） | 常见扣分点 |
|------|-----------|-----------|
| 任务完成情况 | 25-30% | 关键指标未按期完成、技术路线重大调整 |
| 经费执行 | 15-20% | 经费支出率过低、自筹资金到位率低、课题间不均衡 |
| 组织管理 | 10-15% | 人员变动未报批、法人责任制落实不到位 |
| 人员投入 | 5-10% | 骨干人员变动、投入工时不足 |
| 风险应对 | 5-10% | 未预判关键技术风险、无备选方案 |
| 示范应用 | 10-15% | 停留在可研阶段未实质落地 |
| 知识产权 | 5-10% | 专利/软件著作权产出不足 |

## 二、常见扣分点（评审红线）

1. **经费执行率过低**：国拨经费支出仅23%，自筹仅10%
2. **技术路线重大调整**：因外部因素（如芯片法案）被迫换方案
3. **关键指标延期**：如SoC布图登记证书未按期获取
4. **自筹资金不到位**：多个课题自筹到位率仅50%
5. **课题间经费不均衡**：部分单位支出率为0
6. **示范工程未落地**：停留在可研阶段
7. **人员变动频繁**：未及时办理调整手续

## 三、任务书的考核指标体系

采用三级嵌套表格：
```
项目目标 -> 预期成果 -> 考核指标
```
每个指标含：已有值 -> 中期值 -> 完成值 三列基线对比

考核方式前置约定：第三方测试 / 专家评审 / 现场见证

## 四、任务书 vs 申报书差异

| 维度 | 申报书 | 任务书 |
|------|--------|--------|
| 性质 | 申请书 | 正式合同（法律约束力） |
| 经费 | 概算 | 刚性分配 |
| 指标 | 承诺指标 | 验收依据，不得降低 |
| 验收 | 未约定 | 验收方法前置约定 |
| 签章 | 申请人+单位 | 双方签章，一式六份 |
| 协议 | 不需要 | 需附所有单位合作协议 |

## 五、项目执行注意事项

从评审意见中提炼：
1. 经费支出要跟上进度，避免前松后紧
2. 重大技术调整要及时报批
3. 自筹资金要提前落实
4. 各课题经费要均衡推进
5. 示范工程要提前启动，不要拖到最后
6. 人员变动及时办理手续
7. 考核指标逐条对应，不遗漏
8. 突出亮点弥补短板（如论文多可弥补经费问题）
